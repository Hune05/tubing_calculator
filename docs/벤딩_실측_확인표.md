# 전선관 벤딩 실측 확인표 (2026-09-26)

앱의 전선관 벤딩 값이 현장에서 맞는지 한 번 꺾어 보고 적는 표입니다. **앱은 고치지 않았습니다**(사용자 지시: 벤딩은 확인만).
앱 값은 앱 계산 함수를 그대로 불러 뽑은 값입니다. 설명서 값은 Greenlee·Klein·IDEAL·Gardner Bender 벤더 설명서 방식입니다.
모든 예는 **22mm(3/4") 전선관, 앱 기본 설정**(테이크업 152.4, CLR 114.3, 게인 81.2, 수축량 자동 공제 켬)입니다.
설정을 바꿨다면 앱 값이 달라지니 앱에서 같은 값을 넣어 다시 읽으십시오.

튜브 벤딩(Swagelok 방식)은 09-23 독립 모델 비교에서 0.5mm 넘게 어긋난 곳이 없어 이 표에 넣지 않았습니다.

---

## 0. 먼저: 벤더 테이크업이 맞는지 (앱과 설명서가 같은 곳)

| 입력 | 앱 마킹(관 끝에서) | 꺾는 법 | 꺾은 뒤 잴 것 | 기대값 | 실측 |
|---|---|---|---|---|---|
| 90° 스텁 300 | 147.6 | 마킹에 벤더 **화살표**를 맞추고 90° | 바닥에서 관 끝(등)까지 스텁 높이 | 300 |  |

- 300에서 어긋나면 그 차이만큼 테이크업(152.4)이 이 벤더와 다릅니다. 설정의 실측 캘리브레이션으로 먼저 맞추고 아래를 하십시오.

## 1. 백투백 (앱 값은 맞음, 벤더 표시만 주의)

| 입력 | 앱 2번 마킹 | 설명서 2번 마킹(별표 방식) | 차이 | 꺾은 뒤 잴 것 | 기대값 | 실측 |
|---|---|---|---|---|---|---|
| [300, 90°] [800, 90°] | 865.1 (화살표에 맞춤) | 1017.5 (별표에 맞춤) | 152.4 | 두 스텁 바깥면 사이 | 800 |  |

- 앱 값은 **두 번째도 화살표에, 벤더를 첫 벤드와 같은 방향으로** 놓을 때 맞습니다(504/504건 일치).
- 설명서처럼 두 번째를 **별표**에 맞추려면 1017.5에 마킹해야 합니다. 앱 값(865.1)에 별표를 대면 152.4mm 짧아집니다.

## 2. 오프셋 (앱과 설명서가 다름)

앱 입력: 높이 100, "장애물 앞 시작 거리" 500. 설명서 방식: 장애물까지 500이고, 장애물 쪽 마킹은 500에 수축(30°는 1/4"/인치, 45°는 3/8"/인치)을 더합니다. 끝 쪽 마킹은 거기서 높이×배수(30°는 2.0, 45°는 1.414)를 뺀 자리입니다.

| 각 | 앱 1번 / 2번 | 설명서 1번(끝 쪽) / 2번(장애물 쪽) | 앱 간격 | 설명서 간격 | 실측: 높이가 다 올라간 자리(관 끝에서) | 실측: 오프셋 높이 |
|---|---|---|---|---|---|---|
| 30° | 526.8 / 724.4 | 325.0 / 525.0 | 197.6 | 200.0 |  |  |
| 45° | 541.4 / 674.5 | 396.1 / 537.5 | 133.1 | 141.4 |  |  |
| 60° | 557.7 / 652.5 | 430.0 / 550.0 | 94.8 | 120.0 (배수 1.2) |  |  |

- 앱은 첫 마킹을 "시작 거리 + 수축" 자리에 찍고, 두 번째를 그보다 장애물 쪽으로 찍습니다. 그래서 **장애물까지 거리를 넣으면 오프셋이 한 간격만큼 늦게 섭니다.** 30°면 약 200mm이고, 장애물에 닿습니다.
- 앱 간격이 설명서보다 짧습니다. 60°는 25mm나 차이 나서 **오프셋 높이가 모자랄 수 있습니다.** 꺾은 뒤 높이를 재 보십시오.
- 오늘 쓰시려면: 장애물 쪽 마킹 = 장애물까지 + 수축, 끝 쪽 마킹 = 그 − 높이×배수로 **손으로** 찍으십시오(설명서 방식).

## 3. 3점 새들 (앱과 설명서가 다름)

앱 입력: 높이 100, 가운데 45°(양옆 22.5°), 시작 거리 500.

| | 옆 1 | 가운데 | 옆 3 | 옆↔가운데 간격 |
|---|---|---|---|---|
| 앱 마킹 | 539.8 | 775.5 | 1053.1 | 235.7 / 277.6 |
| 앱이 뜻한 자리(1번 = 시작 거리) | 500.0 | 735.7 | 1013.3 | |
| 설명서 방식 | 가운데 − 250 | 장애물 중심 + 18.8 (3/16"/인치) | 가운데 + 250 | 250 / 250 (2.5×높이) |

- 앱은 첫 마킹에 **양쪽 수축(39.8)을 다 더해** 새들 전체가 약 40mm 늦게 섭니다. 높이 200이면 약 80mm 늦습니다.
- 설명서 방식에서 가운데 마킹은 벤더의 **노치(물방울 모양)**에 맞춥니다.

| 실측 | 기대 | 실측값 |
|---|---|---|
| 새들 꼭대기 가운데 자리(관 끝에서) | 장애물 중심 |  |
| 새들 높이 | 100 |  |

## 4. 90°를 넘는 각 (앱 값이 틀림)

| 입력 | 앱 자를 길이 | 기하 자를 길이(CLR 114.3 중심선) | 차이 | 실측 |
|---|---|---|---|---|
| [300, 100°] [300] | 477.3 | 527.1 | −49.8 |  |
| [300, 120°] [300] | 336.7 | 443.4 | −106.7 |  |
| [300, 150°] [300] | −331.5 (음수) | 46.1 | 만들 수 없음 |  |

- 앱은 90° 넘는 각의 게인을 크게 잡아 자를 길이가 짧게(150°부터 음수) 나옵니다. 91~170° 80건 가운데 30건이 음수입니다.
- 90°를 넘는 벤드는 앱 값을 쓰지 말고 실측으로 정하십시오.

## 5. 그 밖에 알고 쓰실 것
- 스텁이 테이크업보다 짧으면(22mm에서 152.4 미만) 마킹이 음수로 나오는데 경고가 없습니다. 예: 스텁 125 → −27.4.
- CLR 114.3은 NEC 9장 표 2의 **최소 반경**입니다. 벤더의 실제 반경(예: Greenlee 841은 130.2)과 다를 수 있어서, 90° 아닌 각의 마킹이 몇 mm 달라집니다(45°에서 약 4.6mm).
- 유압 벤더 표(22mm 셋백 175 등)는 출처가 없습니다. Greenlee 555C는 3/4" EMT 90° 공제를 225.4로 적어 둡니다. 유압 벤더는 반드시 0번 표처럼 한 번 실측하십시오.
