# 필드 헬퍼(현장 도우미)에 맞게 추가할 것 (2026-09-25)

전제: 통신이 자주 끊기는 현장에서 혼자(또는 몇 사람이) 쓰는 도구. 새 기능을 새로 지어내기보다,
**앱 안에 이미 있는 좋은 패턴인데 빠진 곳**과, **한국 현장 관행상 당연히 있어야 하는데 없는 것**을
코드를 직접 뒤져서 찾았습니다.

## 1. 동기화 대기 표시가 정작 제일 중요한 화면에 없다 (작음, 바로 가능)

- `PendingWritesBanner`("서버에 아직 안 올라간 저장이 있습니다")가 이미 있고, 재고·컷팅·형강·내 일정
  화면에는 붙어 있습니다. 그런데 정작 **작업 일지 메인·상세 화면**(현장에서 가장 자주, 가장 길게 쓰는
  화면)에는 없습니다.
- 통신 없는 현장에서 일지를 쓰고 나서 "저장했습니다"만 보고 안심했다가, 사실 폰에만 있고 서버엔
  안 올라간 걸 나중에 알게 되는 상황이 제일 위험합니다.
- 할 일: `work_log_main_screen.dart`·`project_detail_page.dart`에 같은 배너를 붙인다.

## 2. 홈 화면에 "재고 부족" 배지가 없다 (작음)

- 재고 부족 판정(`isShortStock`)은 이미 있고 재고 화면 안에서는 보입니다. 홈 화면에는 이미
  "오늘 일지 미작성 N건" 배지가 있는데(N2), 같은 자리에 "재고 부족 N건"은 없습니다.
- 현장 나가기 전에 홈 화면만 보고 "관 몇 개 챙겨야겠다"를 알 수 있어야 합니다. 지금은 재고 화면에
  일부러 들어가야만 압니다.
- 할 일: `fetchMissingReportCount`처럼 `fetchLowStockCount`를 만들어 홈 배지에 추가.

## 3. 현장 사진에 날짜·현장명·위치 도장이 없다 (중간, 현장 관행에 필요)

- 작업 일지 사진(`photo_store.dart`)은 그냥 사진 파일만 저장합니다. 촬영 시각·위치·현장 이름을
  사진 위에 찍어 두지 않습니다.
- 한국 현장에서 "사진대지"(작업 증빙 사진)는 날짜·현장명이 사진에 찍혀 있는 걸 기본으로 칩니다.
  나중에 사진만 따로 꺼내 봐도(카톡으로 보내거나 PDF에서 잘라내도) 어디·언제 사진인지 알 수 있어야
  합니다. 지금은 앱 안에서만 프로젝트와 연결돼 있어서, 사진이 앱 밖으로 나가는 순간 정보가 사라집니다.
- GPS는 이미 날씨 기능에서 쓰고 있어(`mobile_menu_page.dart`) 새로 권한을 받을 필요는 없고,
  위치를 못 가져와도(권한 거부·GPS 꺼짐) 도장에서 위치만 빼면 됩니다.
- 할 일: 사진 저장 직전에 캔버스로 하단에 "2026-09-25 14:32 · 현대 스마트팩토리 3동 · 위치 못 가져옴/좌표"
  한 줄을 찍어 넣는다. 켜고 끄는 설정도 하나 둔다(모든 현장이 이걸 원하지 않을 수 있음).

## 4. 공수(출근·퇴근) 기록이 "투입 인원 수"에서 멈춰 있다 (중간~큼)

- 오늘 작업의 "투입 인원"은 숫자만 넣습니다(1명, 2명 …). 실제 공수 계산(몇 시부터 몇 시까지 있었는지)은
  없습니다.
- 하루 끝에 "오늘 현장에서 몇 시간 있었나"를 손으로 기억해 따로 적는 대신, 도착할 때 한 번 누르고
  나갈 때 한 번 누르면 자동으로 남는 게 필드 도구다운 방향입니다. 급여·정산 근거로도 쓸 수 있습니다.
- 할 일: 오늘 작업 카드에 "출근" / "퇴근" 두 단추, 눌린 시각을 저장. 기존 "투입 인원" 숫자는 그대로
  두고 옆에 붙이는 정도로(당장 지우거나 바꾸지 않음).
