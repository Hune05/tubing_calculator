# 내 일정 관리 · 내 프로젝트 개선 (2026-09-23)

잘나가는 앱(구글·네이버·카카오 캘린더, TickTick / Notion·Asana·Fieldwire)과 견줘 부족했던 것 가운데 이날 고친 것. 폰에서 돌려 본 것과 테스트로만 확인한 것을 나눠 적었다.

## 묶음 1 — 내 일정 (커밋 2702b10)

| 항목 | 한 것 | 저장 칸(예전 자료는 그대로 읽힘) |
|---|---|---|
| 끝나는 시각 | 편집 창에 "끝나는 시간(선택)" 단추, 카드에 `09:00~10:30`, 시작보다 앞이면 막음 | `endTime`(ISO) |
| 겹침 판정 | 둘 다 끝 시각이 있으면 구간으로(두 시간 회의 중간에 시작하는 것도 겹침), 없으면 예전 1시간 창 | — |
| 반복 종류 | 매일 · 평일마다 · 매주 · 격주 · 매월 · 매년 | `recurrence`: daily/weekdays/weekly/biweekly/monthly/yearly |
| 반복 끝 | "반복 끝 (계속)" 단추로 날짜 지정 | `recurrenceUntil`(날짜 ISO) |
| 이 회차만 / 이후 모두 / 모든 회차 | 반복 일정 회차에서 고치거나 지울 때 묻는다. 이 회차만 → 옛 문서에 뺀 회차 적고 새 문서(반복 없음). 이후 모두 → 옛 문서 반복 끝을 그 회차 하루 전으로, 새 문서(반복 이어짐). 모든 회차 → 시작일은 그대로 두고 내용만 | `recurrenceExceptions`(뺀 회차 키 목록) |
| 알림 여러 개 | 최대 5개 골라 두기(10분 전 + 하루 전 같이) | `reminders`(분 목록), 예전 칸 `reminderMinutesBefore`도 같이 씀(제일 이른 것) |
| 종일 알림 | 전날 18:00 · 전날 09:00 · 당일 08:00 | 자정 기준 분(음수는 당일 아침) |
| 메모 | 편집 창 메모 칸, 카드에 한 줄 | `note` |
| 완료 숨김 | 범례 맨 앞 "완료 숨김" 칩 | 화면만 |
| 홈 "오늘 N건" | 반복 끝·뺀 회차를 반영 | — |

폰 알림: 매일·매주·매월(28일 이하)·매년은 폰 되풀이 예약으로, 격주·평일·반복 끝·뺀 회차·날짜가 밀리는 매달은 한 번씩 잡고 앱을 열 때 다시 잡는다(`rescheduleDriftingMonthlyReminders`). 뺀 회차가 있는 매주 일정도 되풀이 예약을 쓰지 않으니 뺀 날에 안 울린다.

## 묶음 2 — 내 프로젝트 협업 (커밋 246d93c)

| 항목 | 한 것 | 저장 칸 |
|---|---|---|
| 누가 썼는지 | 일지·이슈에 만든 사람·시각, 고친 사람·시각. 일지 줄·이슈 상세에 "차재훈 9/23 18:02 · 김반장 9/24 09:10 고침" | `author`·`authoredAt`·`updatedBy`·`updatedAt` |
| 덮어쓰기 방지 | 저장 직전에 서버 문서를 읽어(5초, 안 되면 폰 캐시) 일지·이슈·일정·단계를 **아이디로 합친다**. 서버에만 있는 항목(다른 폰이 넣은 것)은 살리고, 같은 아이디는 updatedAt 늦은 쪽, 지운 아이디는 어느 쪽에 있어도 뺀다. 아이디 없는 예전 일지는 읽을 때 아이디를 붙인다 | `deletedIds`, 일지 `id` |
| 이슈 담당자 | 등록·상세에서 "나 · 사용자 목록 · 직접 적기", 목록에 "OO 담당", 이슈 탭 "내 이슈" 필터 | `assignee` |

합치지 않는 것: 자재(materials)는 아이디가 없어 폰 것이 이긴다(예전과 같음). 프로젝트 이름·상태·진행률 같은 낱개 칸도 폰 것이 이긴다.
