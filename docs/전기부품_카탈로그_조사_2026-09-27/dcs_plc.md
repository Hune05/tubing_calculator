# DCS·PLC·계장 캐비닛 부품 정면 치수 (mm) - 통합 정리

표기 순서는 가로(W) x 세로(H) x 설치면 깊이(D). 확정 = 서로 다른 문서 2곳 이상 일치, 단일 = 문서 1곳, 못 읽음 = 그림만 있고 숫자 못 읽음.
세부 표(정면 특징, 출처 URL, 국내 근거)는 같은 폴더의 part_A_plc.md, part_B_dcs.md, part_C_barrier_switch.md, part_D_relay_power.md. 내려받은 원본은 w2\, dcs\, abb\, hw\, C\ 하위 폴더.
주의: 검색 요약이 세로·깊이를 뒤바꾸거나 틀린 값을 준 사례가 여러 번 있어(QUINT-PS/10, KFD2-STC4) 원문 데이터시트만 채택했다. 웹 검색 한도(200회)가 끝나 일부는 두 번째 출처를 못 구했다.

- 요꼬가와 FIO: 32.8mm 세로 모듈이 8칸 나란히(왼쪽 I/O, 오른쪽 전원 2칸), 위쪽 상태 LED, 가운데 커넥터 창, 아래 잠금 나사. 19인치 랙.
- 에머슨 DeltaV: 41.8mm 둥근 케이스에 원형 정보 창과 LED 세로줄, 아래 RJ-45 2개. CHARM 12칸 베이스플레이트에 번호 1~12.
- ABB: TP830 위 CPU, 위쪽 LED 줄, 이더넷 RJ45 2개, INIT 단추. S800은 45mm 모듈 + 3줄 나사 단자 MTU.
