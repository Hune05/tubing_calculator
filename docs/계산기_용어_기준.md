# 현장 계산기 화면 글 기준 (2026-09-26)

단위 환산·전기 계산기·압력 시험 계산기·4-20mA 계산기의 화면 글·도움말·결과 줄·PDF에 쓴다.
근거: 화면 글 전수 점검(법정계량 기술기준, KEC, KGS·KOSHA, 교정 성적서 자료)과 신뢰 앱 비교.

## 말투
- 끝맺음은 **습니다/십시오**. "요"로 끝내지 않는다.
- 단추는 명사형(저장·지우기·새로 시작).
- 설명 줄에 줄표(" — ")를 쓰지 않는다. **": "** 또는 마침표로 끊는다.
- 한 문장은 짧게. 괄호 안에 또 설명을 넣지 않는다.
- 내가 지은 순우리말(셈, 몫, 까닭, 어림, 잰)을 쓰지 않고 현장에서 쓰는 기술 용어를 쓴다.

## 그대로 두는 말
