# 형강 브라켓 상용 앱 비교 (2026-10-11)

사용자: "형강 브라켓 쪽도 싹 뜯어고치자. 상용 앱과 우선 비교 분석하고".
지금 앱 코드(lib/src/presentation/steel_bracket/ 네 파일)를 읽고, 시험 화면으로 네 모양 화면과 지시서 그림을 찍어 보고, 상용 도구는 공식 페이지·도움말·앱 소개 글로 조사했다(직접 써 보지는 않음).

## 1. 상용 도구가 하는 것

| 갈래 | 도구 | 브라켓에 관계있는 기능 |
|---|---|---|
| 서포트 구성기 | Hilti PROFIS Installation, fischer FIXPERIENCE, MÜPRO, Atkore(Unistrut), nVent CADDY | 표준 모양 템플릿에서 고르기, 하중 넣으면 사용률(%) 막대, 앵커 검토, 부품표(BOM)·설치 설명서, DXF·Revit 보내기, 행거 종류마다 그림 들어간 PDF |
| 플랜트 서포트 | Smart 3D, AVEVA, Bentley OpenPlant, CADWorx | 표준 서포트 수백 종, 도면에 여러 면 그림·품번·총수량·BOM·노트 칸, 일괄 출력 |
| 철골 상세 | Tekla, Advance Steel, SDS2 | 부재 번호(품번), 단품도(부재 하나씩 길이·구멍·끝 모양)·조립도, 용접·볼트 표시, 그림 들어간 톱 절단 목록, 조립 1개당 수량, NC·DXF |
| 접합·하중 | IDEA StatiCa, RISA, SkyCiv, ClearCalcs | 용접 크기 자동 제안, 베이스 판·앵커 검토, 캔틸레버 처짐 |
| 모바일 | 중량 계산기, 절단 최적화(Cutter, Linear Cutting, OptiCut) | 중량·단가, 원자재 배치, 잔재 재고 다시 쓰기, 비스듬한 끝 맞물려 배치 |

- 폰에서 브라켓 모양을 골라 제작도·자를 것 표까지 내는 앱은 찾지 못했다. 이 자리는 비어 있다.
- 제작자가 도면에서 기대하는 것(상용 도구 공통 출력과 제작도 점검표): 품번, 규격·재질, 자를 길이와 수량(1조당 × 조수), 가새 끝 각도, 부재별 구멍 표, 용접 기호와 크기(각장인지 목두께인지), 표면 처리, 전체 치수와 기준면, 표제란(도면 번호·개정), 일반 노트(단위·공차), 무게.

## 2. 지금 앱

- 모양 4개(ㄱ자·삼각·문형·T자), 이음 3가지(기둥 통과·가로대 통과·45° 연귀), 형강 4종(앵글·찬넬·평철·각파이프), 기둥·가로대 줄 구멍, 베이스 판(문형·T자, 정사각, 앵커 0·2·4), 만들 개수, 원자재 본수, 무게, 카톡 글, 지시서 PDF(그림 한 장 + 표), 저장한 규격, 최근 계산 기록.
- 좋은 점: 이음에 따라 짧아지는 길이, 가새 긴 변·짧은 변과 각도절단기 각도, 구멍이 부재 밖·가새 끝에 걸리면 알림, 원자재 본수까지 한 화면에서 끝난다.

## 3. 비교해서 모자란 것

### 틀린 것 (제작자가 잘못 만들 수 있음)
1. **구멍이 다른 면에 그려진다.** ㄱ자·삼각 그림은 옆에서 본 그림이라 벽에 붙는 면과 가로대 위 면이 선으로만 보인다. 그런데 기둥 구멍(벽 붙는 면)과 가로대 구멍(위 면)이 보이는 면 위에 원으로 찍혀 있어, 그림만 보면 다른 다리에 뚫게 된다. 문형·T자 가로대 구멍도 같다(베이스 판 구멍은 위에서 본 판에 따로 그려 맞다).
2. **앵글·찬넬이 어느 쪽을 보는지 없다.** 단면 표시가 없어 다리 방향을 알 수 없다. 구멍이 다리 어디에 오는지(게이지, 다리 뒤에서 구멍 줄까지)도 정하지 않는다(그림은 변 가운데).

### 도면 (상용 수준에 모자람)
3. 품번이 없다: 그림·자를 것 표·구멍 줄이 같은 번호(①기둥 ②가로대 ③가새 ④베이스 판)로 묶이지 않는다.
4. 그림에 치수가 적다: 전체 가로·세로와 가새 자리뿐이다. 토막 길이(이음으로 짧아진 값), 구멍 자리, 가새 길이·끝 각도가 그림에 없다.
5. 토막별 그림(단품도)이 없다: 토막 하나마다 길이·끝 모양(각도)·구멍 자리를 그린 그림이 없어, 자르는 사람이 표 글만 보고 마킹해야 한다.
6. 용접이 주황 삼각뿐이다: 용접 기호, 각장, 전둘레 여부가 없다. "따로 적지 않은 용접은 각장 ○ 전둘레" 같은 노트 한 줄도 없다.
7. 재질·표면 처리·공차·표제란이 없다: 재질(SS275), 표면(무도장·방청 도장·용융아연도금), 공차, 도면 번호·개정·작성자 칸이 없다(작성·검토·승인 칸만 있음).
8. 규격 표기가 앱 이름("앵글 50x50x5")뿐이다. 도면 관례 표기(L-50×50×5, ㄷ-100×50×5, FB-50×6, □-50×50×2.3, PL-9×150×150)와 단위 중량(kg/m)이 없다.

### 재료·구멍·판
9. 가새도 기둥·가로대와 같은 규격만 된다(가새는 평철·작은 앵글을 많이 씀).
10. 규격 목록에 H형강·스트럿·립C형강·부등변 앵글이 없다(형강 컷팅 규격표에는 이미 있음).
11. 구멍: 장공(U볼트 자리 맞춤용)이 없고, 볼트 크기에 비해 끝에서 너무 가까운 구멍(연단 거리)을 알리지 않는다.
12. 베이스 판: 정사각만, 리브(보강판) 없음. ㄱ자·삼각에는 벽 붙임 판이 없다.

### 화면
13. 그림이 입력 칸 맨 아래에 있어 값을 넣으면서 그림을 못 본다. 철판 가공(위 그림 고정 + 아래 탭)과 틀이 다르다. 숫자 칸을 눌러도 값 전체가 골라지지 않는다. 그림 칸이 300점으로 작다.

### 연결·계산 (새 기능, 정해 주셔야 함)
14. 베이스 판·벽 붙임 판을 철판 가공(레이저 절단)으로 넘기기 — 판 크기·구멍이 그대로 넘어가 DXF까지.
15. 자를 것을 형강 컷팅으로 보내기 — 새 프로젝트를 만들어 넣음(기존 프로젝트는 안 건드림).
16. 여러 브라켓 한 묶음 — 한 현장의 ㄱ자 10개 + 문형 4개를 모아 원자재 합산·지시서 한 번에.
17. 하중 확인(참고) — 가로대 끝 하중(kg)을 넣으면 휨 사용률·처짐, 가새 누름, 벽 앵커 당김을 대략 보여 줌. 근거(허용 응력·단면 성능)를 확인해야 하고 "참고값"으로만.
18. 새 모양 — 2단 가로대(문형 다단), 천장 매달기(전산볼트 + 가로대), 벽 붙임 판 ㄱ자.
19. 입체 보기 — 철판 가공처럼 돌려 보기(앵글 방향 확인용).

## 4. 제안 순서

- 먼저(1~13): 틀린 것(1·2) → 도면(3~8) → 재료·구멍·판(9~12) → 화면 틀(13). 철판 가공을 고칠 때와 같은 방식으로 한 번에 손보고 실기기로 확인한다.
- 정해 주셔야 할 것(14~19): 새 기능이라 하실지 고르셔야 한다. 하중 확인(17)은 안전에 걸려 근거부터 확인해야 한다.
