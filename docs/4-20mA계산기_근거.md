# 4-20mA 계산기 — 식과 기준값의 근거 (2026-09-26)

홈 "현장 작업" → 4-20mA 계산기. 계산은 `lib/src/presentation/instrument/signal_calc.dart`.
**최종 판정은 계기 데이터시트와 발주처·교정 절차서의 허용 오차를 따른다.**

## 환산
- mA = 4 + 16 × (측정값 − 0% 값) ÷ (100% 값 − 0% 값). 범위가 거꾸로(100~0)거나 음수(−50~150°C)여도 같은 식.
- 제곱근(차압 유량): mA는 차압에 비례, 유량 % = 10 × √(차압 %). 유량 50% = 차압 25% = 8mA.
  전송기 안에서 제곱근을 풀어 내보내면(출력이 유량에 비례) 선형으로 둔다.
- 1-5V: 250Ω에 흐르는 4~20mA = 1~5V(옴의 법칙).

## 신호 상태 — NAMUR NE43
- 측정 신호 3.8~20.5mA(3.8~4 = 0% 아래, 20~20.5 = 100% 위, 측정은 맞음), 고장 신호 ≤3.6mA 또는 ≥21mA.
  3.6~3.8·20.5~21은 정해지지 않은 구간으로 보인다.
- 출처: instrumentationtools.com "What is NAMUR NE 43", romilly.co.uk "Fault indication in Smart transmitters",
  industrialmonitordirect.com NE43 설명 — 세 곳 값이 같다. NE43 원문(유료)은 못 봄.

## 교정 점검
- 읽은 값이 mA: 오차 % = (읽은 mA − 이론 mA) ÷ 16mA × 100. 이론 mA는 **넣은 값**(기준기로 실제 가한 값)으로 셈 —
  점(25% 등)과 조금 달라도 된다. 비우면 점 값.
- 읽은 값이 지시값(DCS·지시계): 오차 % = (지시값 − 넣은 값) ÷ 측정 범위 × 100.
- 허용 오차(± 스팬 %)는 사용자가 넣는다(계기 정확도·절차서). 앱이 정한 기본값은 없다. 판정은 |오차| ≤ 허용 오차.
- 5점(0·25·50·75·100%), 상승·하강(히스테리시스)은 아직 없다.

## 루프 전압
- 계기 단자 전압 = 전원 − 전류 × 루프 저항 합(HART·입력 저항 + 배리어 + 전선 왕복). 20mA와 21mA(NE43 고장 신호의 시작)에서 본다.
  21mA에서 계기 최소 전압 이상이면 "충분".
- HART: 루프 저항 230Ω 이상(보통 250Ω) — HART 사양 230~1100Ω(control.com·Lesman·ProComSol 자료).
- 계기 최소 전압 기본값 10.5V: Rosemount 3051(4-20mA HART) 전원 10.5~42.4Vdc, 최대 루프 저항 = 43.5 × (전원 − 10.5)
  (Rosemount 3051 데이터시트). 43.5 = 1/0.023 → 제조사는 약 23mA로 셈해 이 앱(21mA)보다 여유를 더 둔다.
- 전선 저항: 전기 계산기와 같은 IEC 60228 2종 구리 20°C 값(0.75·1.0·1.5·2.5sq). 1.25sq 등은 저항을 직접 넣는다.

## 역산(지시값 → 흐르는 mA)
- 환산 탭에서 "측정값"으로 DCS·지시계 값을 넣으면 제목이 "흐르는 전류(역산)"으로 바뀐다(mA = 이론식).
- 교정 점검에서 "지시값"으로 읽으면 점마다 "흐르는 전류(역산) N mA"를 보인다 — 지시값을 이론식으로 되돌린 값이라,
  DCS 스케일링이 맞다는 전제의 계산값이다(실제 전류는 멀티미터로 잰 값이 기준).

- 한 기록 = 태그·계기·제조사·모델·기준기·작업자·메모 + 범위·단위·제곱근·읽은 값 종류·허용 오차 + 조정 전(As Found)·
  조정 후(As Left) 다섯 점. 최종 판정은 조정 후가 있으면 조정 후, 없으면 조정 전.

  메모, 작업자·확인 서명 칸. 미리보기로 먼저 보이고 공유는 단추를 눌러야만 된다.
