# 필드 헬퍼(현장 도우미)에 맞게 추가할 것 (2026-09-25)

전제: 통신이 자주 끊기는 현장에서 혼자(또는 몇 사람이) 쓰는 도구. 새 기능을 새로 지어내기보다,
**앱 안에 이미 있는 좋은 패턴인데 빠진 곳**과, **한국 현장 관행상 당연히 있어야 하는데 없는 것**을
코드를 직접 뒤져서 찾았습니다.

## 1. 동기화 대기 표시가 정작 제일 중요한 화면에 없다 — ✅ 확인해 보니 이미 있었음(2026-09-25)

- `PendingWritesBanner`("서버에 아직 안 올라간 저장이 있습니다")가 이미 있고, 재고·컷팅·형강·내 일정
  화면에는 붙어 있습니다. 그런데 정작 **작업 일지 메인·상세 화면**(현장에서 가장 자주, 가장 길게 쓰는
  화면)에는 없습니다.
- 통신 없는 현장에서 일지를 쓰고 나서 "저장했습니다"만 보고 안심했다가, 사실 폰에만 있고 서버엔
  안 올라간 걸 나중에 알게 되는 상황이 제일 위험합니다.
- **고쳐서 다시 보니**: 컴포넌트 이름(`PendingWritesBanner`)만 찾아서 없는 줄 알았는데,
  `work_log_main_screen_banners.dart`의 `_buildSyncBanner()`가 이미 저장 대기·사진 업로드
  대기까지 훨씬 자세히 보여 주고 있었고(`work_log_main_screen.dart`에 실제로 붙어 있음),
  `project_detail_page.dart`에도 이미 머리에 작은 "저장 중" 표시가 있었습니다. 잘못된
  제안이었습니다. 코드 변경 없음.

## 2. 홈 화면에 "재고 부족" 배지가 없다 — ✅ 고침(2026-09-25)

- 재고 부족 판정(`isShortStock`)은 이미 있고 재고 화면 안에서는 보입니다. 홈 화면에는 이미
  "오늘 일지 미작성 N건" 배지가 있는데(N2), 같은 자리에 "재고 부족 N건"은 없습니다.
- 현장 나가기 전에 홈 화면만 보고 "관 몇 개 챙겨야겠다"를 알 수 있어야 합니다. 지금은 재고 화면에
  일부러 들어가야만 압니다.
- `lib/src/presentation/inventory/pages/low_stock_count.dart`: `fetchLowStockCount()`가
  `inventory` 컬렉션을 읽어(통신 없으면 폰 캐시로) 남의 개인 재고를 뺀 부족 건수를 센다
  (`countLowStock`, 자재 현황 화면과 같은 기준 `canSeeStock`+`isShortStock`).
- 폰 홈 "자재 현황" 단추에 "N건 부족" 배지(주황, `AppColors.caution`), "오늘 일지 미작성"
  배지와 같은 자리·같은 모양. 자재 현황·자재 통합 관리 화면에서 돌아오면 다시 읽는다.
- 시험: `test/low_stock_count_test.dart`. PC 홈은 원래 미작성 배지도 없어서(N2가 폰만 한
  것과 같은 이유) 이번에도 폰만.

## 3. 현장 사진에 날짜·현장명·위치 도장이 없다 — ✅ 고침(2026-09-25)

- 작업 일지 사진(`photo_store.dart`)은 그냥 사진 파일만 저장합니다. 촬영 시각·위치·현장 이름을
  사진 위에 찍어 두지 않습니다.
- 한국 현장에서 "사진대지"(작업 증빙 사진)는 날짜·현장명이 사진에 찍혀 있는 걸 기본으로 칩니다.
  나중에 사진만 따로 꺼내 봐도(카톡으로 보내거나 PDF에서 잘라내도) 어디·언제 사진인지 알 수 있어야
  합니다. 지금은 앱 안에서만 프로젝트와 연결돼 있어서, 사진이 앱 밖으로 나가는 순간 정보가 사라집니다.
- GPS는 이미 날씨 기능에서 쓰고 있어(`mobile_menu_page.dart`) 새로 권한을 받을 필요는 없고,
  위치를 못 가져와도(권한 거부·GPS 꺼짐) 도장에서 위치만 빼면 됩니다.
- 할 일: 사진 저장 직전에 캔버스로 하단에 "2026-09-25 14:32 · 현대 스마트팩토리 3동 · 위치 못 가져옴/좌표"
  한 줄을 찍어 넣는다. 켜고 끄는 설정도 하나 둔다(모든 현장이 이걸 원하지 않을 수 있음).
- `lib/src/presentation/my_work_logs/models/photo_stamp.dart`의 `stampPhoto()`: 사진 아래에 반투명 검정 띠를 깔고
  현장 이름·촬영 시각(`yyyy-MM-dd HH:mm`)·(있으면) "시/구" 수준 위치를 흰 글씨로 찍는다. 위치는 이미 허용된 권한으로
  마지막 위치만 쓰고(`Geolocator.checkPermission()`만, 새로 묻지 않음) 없으면 그 줄만 뺀다. 글꼴은 앱과 같은
  NotoSansKR.
- **카메라로 막 찍은 사진에만** 찍는다(갤러리에서 고른 옛 사진은 "지금" 시각이 아니므로 제외). `ImagePickerHelper.pickImages`에
  `stampSite`·`siteLabel`을 더해 한 곳에서 처리하고, 로고·도면 사진을 고르는 4곳(보고서 로고, 전선관 배치도, 배치도
  배경 등)은 그대로 안 찍는다.
- 도장 찍는 실제 화면 3곳: 작업 일지 사진 첨부, 이슈(펀치리스트) 등록·완료 사진. 프로젝트 이름을 `DailyReportPage`·
  `PunchListPage`·`PunchDetailPage`에 새로 넘긴다.
- 보고서 양식 설정에 "사진에 현장 이름·날짜·위치 찍기" 켜고 끄기(기본 켬), `ReportStyle.photoStamp`로 서버·폰에 같이 저장.
- 시험: `test/photo_stamp_test.dart`(찍을 줄 고르기, 설정 기본값·저장·예전 저장 형식과 호환, 설정 화면 스위치).

## 4. 공수(출근·퇴근) 기록이 "투입 인원 수"에서 멈춰 있다 (중간~큼)

- 오늘 작업의 "투입 인원"은 숫자만 넣습니다(1명, 2명 …). 실제 공수 계산(몇 시부터 몇 시까지 있었는지)은
  없습니다.
- 하루 끝에 "오늘 현장에서 몇 시간 있었나"를 손으로 기억해 따로 적는 대신, 도착할 때 한 번 누르고
  나갈 때 한 번 누르면 자동으로 남는 게 필드 도구다운 방향입니다. 급여·정산 근거로도 쓸 수 있습니다.
- 할 일: 오늘 작업 카드에 "출근" / "퇴근" 두 단추, 눌린 시각을 저장. 기존 "투입 인원" 숫자는 그대로
  두고 옆에 붙이는 정도로(당장 지우거나 바꾸지 않음).
