## 결선·소손 원인
- 단자 표기 U1·V1·W1·U2·V2·W2 = U·V·W·X·Y·Z = T1~T6(WEG). 국내 KS 표기는 확인 못 함.
- L1·L2·L3 → U·V·W면 축 쪽에서 시계 방향, 두 상을 바꾸면 반대(Siemens·ABB·WEG·HD현대).
- Y-Δ 유리/불리 결선, 접촉기 0.33·0.58배(Siemens Y-Δ 자료). 과부하계전기 0.58배는 주 접촉기(Siemens 용어 "line contactor", 권선 전류가 흐름)에 붙였을 때다: Siemens Industrial Controls Catalog 2019 3장 원문(10-06 확인, 근거는 `전기_접지_전동기보호_근거.md`).
- 소손 원인별 권선 모양(한 상·세 상 고르게·세 상 심함·단상 운전·서지·습기)은 EASA 고장 분류(글만 사용, 사진 저작권 EASA).
