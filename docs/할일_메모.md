# 할 일 메모 (다음에 이어서 할 것)

Claude 세션은 끝나면 기억이 사라지므로, 이어서 할 일을 여기에 적어 둔다. 새 세션에서 "docs/할일_메모.md 보고 이어서 해줘"라고 하면 된다.

## 확인이 필요한 것
- [ ] **Firebase 콘솔에서 익명 로그인이 켜져 있는지** (Authentication → 로그인 방법 → 익명). 본가에 있어서 아직 확인 못 함. 예전에 켠 적이 있을 수 있음.
  - 켜져 있으면: 새 앱을 깔고 한 번 연 뒤 `firestore.rules`를 콘솔 → Firestore → 규칙에 올린다.
  - 꺼져 있으면: 켜고 위와 같이. 켤 수 없으면 규칙은 올리지 말 것(구글 로그인 안 한 사람이 서버를 못 씀).
- [x] 컴파일·테스트: 2026-09-24 클라우드에서 Flutter 3.41.9로 `flutter analyze`(오류 0)·`flutter test`(1,666개 모두 통과) 확인. GitHub에도 자동 검사(`.github/workflows/flutter-test.yml`)를 넣어 올릴 때마다 돈다.
- [ ] 폰·PC에 새로 깔아 화면을 눌러 보는 확인(재고조사 올리기, 씀·채움, 내 것/공용 칩, 리모컨 보내기)은 아직.
- [ ] **수평계·각도기 폰 확인**(센서는 실제 폰에서만 확인 가능): ① 눕혀서 기포가 **높은 쪽**으로 가는지(한쪽 밑에 동전을 괴어 보기), ② 세워서·옆으로 세워서 기포관 방향, ③ 벤딩 각도: 90° 굽힌 관에서 90.0° 가까이 나오는지, ④ 나갔다 들어왔을 때 화면 꺼짐 방지가 설정대로 돌아오는지. 방향이 반대면 `level_page.dart`의 기포 부호 한 곳만 바꾸면 된다.

- [ ] **예전에 튜브 설정을 inch로 바꾼 적이 있으면** 반경·게인·피팅 깊이 값을 한 번 확인(점검 2번: 25.4로 나뉘어 저장됐을 수 있음. 새 코드는 더 망가뜨리지 않지만 이미 바뀐 값은 못 되돌림).
- [ ] 톱날 손실: 튜브 컷팅에서 한 번 확인(점검 14번. 예전에 형강에 맞춰 넣은 값이 튜브에도 남아 있음).

- [ ] **튜브 재고 빼는 곳이 바뀜**(점검 4번): 튜브는 재단 계획 창의 "재고에서 빼기"로. 목록의 "재고 차감"은 부속·예전 튜브 길이만. 폰에서 한 번 해 볼 것.

- [ ] **PC가 윈도우 앱이면** 새로 빌드해 켜지는지 확인(점검 24번, 클라우드에서는 윈도우 빌드를 못 해 봄).

- [ ] **서버 함수 배포**(점검 30·34번): `firebase deploy --only functions`. 발주·채팅 함수 3개를 지울지 물으면 지운다. 서버 알림이 "현장 중요 알림" 채널로 가고 누르면 작업 일지가 열린다.
- [ ] 폰에서 확인: 상태 표시줄이 보이고 화면이 안 겹치는지(35번), 새 일지 날짜 고르기(36번), 재단 계획 창 아래 "재단 설정 · 내보내기"(37번).

- [x] **UI·UX 점검 묶음 U-A**(`docs/UIUX_점검_2026-09-25.md`): X1·X2·X3·X5·X6·X7·X8·X9·X11·X12·F3 고침.
