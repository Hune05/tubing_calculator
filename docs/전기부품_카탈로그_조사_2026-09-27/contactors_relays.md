# 접촉기·열동계전기·타이머·보호계전기 정면 치수 (mm) — 2026-09-27 조사

읽기·웹 조사만 했고 앱 파일은 건드리지 않았다. 치수는 가로(W) x 세로(H) x 설치면 깊이(D). 기억으로 쓴 값 없음.
판정: 확정 = 서로 다른 문서 2건 이상 일치 / 단일 출처 / 못 읽음.
"같은 제조사 문서 2건"은 독립성이 약해서 표에 (동일 제조사)라고 따로 적었다.
주의: 검색 요약은 가로·세로·깊이를 뒤바꾸거나 틀린 사례가 있어 원문 데이터시트·카탈로그 값만 채택했다.
WebSearch 한도(200회)가 소진되어 후반에는 주소를 아는 문서만 읽었다.
