# 전기 계산기 — 표·식의 근거 (2026-09-26 조사)

전기 계산기(홈 "현장 작업" → 전기 계산기)의 숫자는 아래 출처에서 옮겼다. 기억으로 넣은 값은 없다.
결과 화면에도 어느 표·조건으로 셈했는지 적는다. **최종 선정은 설계 도서·제조사 표로 확인한다.**

## 허용전류 — 일반 배선 (`elec_tables.dart`)
- 법 근거: KEC 232.5.2 → KS C IEC 60364-5-52 부속서 B. KEC 표 232.5-1: PVC 70°C, XLPE/EPR 90°C.
- 표 B.52.2~B.52.5(구리, A1·A2·B1·B2·C·D1·D2), B.52.10·B.52.12(방법 E):
  TiSoft IEC 60364-5-52 도움말과 한국 전선업계 자료
  (https://shop.cables.co.kr/images/pdf/iecsize_cable_heoyongjunru.pdf)가 같은 값. B.52.4는 Schneider
  Electrical Installation Guide와도 같다. **D1·D2 열은 한 출처(TiSoft)뿐.**
- F-CV 방법 E·D1·D2 값은 LS전선·대한전선·넥상스 카탈로그와 모두 같다.
- 보정: B.52.14(공기, 30°C 기준)·B.52.15(지중, 20°C)·B.52.17(묶음·한 줄)·B.52.18(직매)·B.52.19(관로).
  표 사이 값은 안전 쪽(더운 쪽, 많은 쪽) 칸을 쓴다.
- HFIX(KS C 3341): LS·KBI 카탈로그가 도체 90°C, 허용전류도 XLPE 90°C 표 값. 표준 원문은 유료라 못 봄.

## 허용전류 — 제어반 내부 배선
- IEC 60204-1:2016 표 6(PVC 구리, 반 안 40°C, 3상), 표 D.1(온도, 40~60°C), 표 D.2(회로 수 2·4·6·9).
  JIS B 9960-1:2019(IEC 60204-1과 같음) 표 이미지와 ABB 자료(0.75~50mm²)가 같은 값. AMD1:2021은 이 표를 안 바꿈.
- 40°C 아래 온도 보정은 표에 없어 1.0으로 둔다(안전 쪽). 9회로 넘으면 60364 B.52.17을 쓴다.

## 전압강하
- 한도: KEC 232.3.9 표 232.3-1 — 저압 수전 조명 3%·기타 5%, 고압 이상 수전 6%·8%. 100m 넘으면
  1m당 0.005%, 더하는 것은 0.5%까지. (2021 전문 기준. 최신 2025-227 HWP 원문은 못 봄.)
- 식: ΔU = k·I·L·(R cosφ + X sinφ), k = 단상 2, 삼상 √3. R = IEC 60228 2종 20°C 저항 ×
  (1 + 0.00393(θ − 20)), θ = 절연체 최고 온도(안전 쪽). X = 0.08 Ω/km(Schneider EIG).
- 참고로 보이는 현장 간이식 35.6·30.8·17.8은 역률 1·20°C·리액턴스 없음이라 작게 나온다.

## 차단기·보호도체
- KEC 212.4.1: IB ≤ In ≤ IZ. 표준 정격: LS ELECTRIC Metasol MCCB 목록(3, 5, 10, 15 … 800A).
- 보호도체: KEC 142.3.2 표 142.3-1(S ≤ 16 → S, ≤ 35 → 16, 넘으면 S/2).
- 전동기 1.25배: KEC에는 없다(예전 판단기준·내선규정, NEC 430.22). 스위치로 켜고 끈다.
- 전동기 차단기 250%: NEC 430.52(역한시 차단기). KEC는 배수를 정하지 않는다(212.6.3).

## 전동기 정격 전류 (`motor_tables.dart`)
- NEC Table 430.250 230V·460V 열: NECA·1999 NEC·NEC 2014 세 사본이 모든 칸 같다.
  NEC 430.6(A)(1): 전선·차단기는 이 표 값으로.
- IE3 4극 60Hz 380V·440V 예: HD현대일렉트릭 저압 유도전동기 카탈로그(2022-03, KS C 4202 프리미엄·IE3)
  https://www.hd-hyundaielectric.com/upload/elec/download/2022_03_11_144803_1.pdf — WEG W22 60Hz와 1~4% 안
  (160·200kW는 이 카탈로그뿐). 한 제조사 예시라 실제 전동기는 명판 값.
- NEC 430.52: 역한시 차단기 250%, 이중소자 퓨즈 175%, 보통 퓨즈 300%, 순시 800%(Design B 고효율 1100%).

## 역률 개선

## 아직 못 넣은 것
- 전선관 굵기(점유율 32%/48%는 내선규정, KEC에는 없음) — 전선 바깥지름 표는 받아 둠(LS F-CV, HFIX).
- AWG 배선(NEC 310.16·UL 508A) — 표는 받아 둠.
