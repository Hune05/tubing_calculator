# 유량 계산: 식과 자료의 근거 (2026-09-26)

화면 `FlowCalcPage`(`lib/src/presentation/flow/flow_calc_page.dart`, 홈 메뉴 연결은 다른 작업에서). 탭: 유속·관 굵기 · 압력손실 · 차압 유량계.
계산은 `flow_calc.dart`, 숫자 자료와 출처는 `flow_data.dart`. 화면 글은 `docs/계산기_용어_기준.md`를 따른다.
**숫자는 두 출처 이상에서 맞는 것만 넣었다. 한 출처뿐인 것은 아래 "넣지 않은 것"에 적었다.**
**최종 값은 설계 기준서·제조사 자료로 확인한다.**

## 공통 입력
- 유량 단위: L/min, m³/h, GPM(US, 1 gal = 3.785411784 L 정의값), kg/h(밀도로 나눔), Nm³/h(기체만, 0°C·101.325kPa 기준 밀도 비로 환산).
- 관: 튜브는 `pressure_test/tube_rating.dart` 목록(SS316 인치 23·mm 17, 공칭 내경 = 외경 − 2 × 두께).
  배관은 `unit_converter/unit_defs.dart` 호칭·외경 표(KS 또는 ASME)에 **두께를 사용자가 넣는다**(표에 스케줄 두께가 없어 두께 표를 새로 넣지 않았다).
  내경 직접 입력도 된다.
- 압력은 게이지 입력, 절대 압력 = 게이지 + 101.325kPa(표준 대기압). kgf/cm² = 98.0665kPa, psi = 6.894757kPa.
- 차압 단위 mmH₂O = 9.80665Pa(관용 값, NIST SP 811). inH₂O는 기준 온도마다 값이 달라 넣지 않았다.

- 90°C 위는 1기압 끓는점(99.97°C)에 가까워 넣지 않았다.

### 공기·질소 (이상기체, −20~200°C)
- 밀도 ρ = P·M/(R·T). R = 8.314462618 J/(mol·K)(2019 SI 정의값, CODATA 2022). 공기 M = 28.9647 g/mol(Engineering ToolBox,
  Wikipedia "Density of air" 28.9652와 0.004% 차이), 질소 M = 28.0134 g/mol(NIST WebBook).
- 압축 계수: 질소 20°C NIST 밀도로 Z = 10bar 0.998, 50bar 0.994, 100bar 1.001, 200bar 1.052. 100bar(절대)까지는 이상기체로
  0.6% 이내라 계산하고, 넘으면 결과에 오차 안내를 붙인다. 공기 Z는 확인한 출처가 없다.
- 점도: Sutherland 식 μ = μ0·(T/T0)^1.5·(T0 + S)/(T + S).
  - 공기 1.716e-5Pa·s, 273.15K, 110.4K(White 값. curiosityFluids, SU2 issue #301). Engineering ToolBox 공기 점도 두 표와 0.1% 이내.
  - 질소 1.663e-5Pa·s, 273K, 107K(White 값, COMSOL CFD 모듈 표 5-2). NIST WebBook 1기압 값과 0°C +0.05%, 20°C 0.00%,
    100°C −0.33%, 200°C −0.85%. Sutherland 상수 자체는 COMSOL 한 곳이라 NIST와 맞춰 본 200°C까지만 받는다.
  - 점도 1% 차이는 난류 마찰 계수에 약 0.2%만 영향이 있다.

### 기름
- 밀도(kg/m³)와 동점도(cSt = mm²/s)를 사용자가 넣는다. μ = ν·ρ. 앱에 기름 값은 없다.

## 유속·레이놀즈 수
- v = Q / (π/4·D²), Re = ρ·v·D/μ. Re < 2300 층류, 2300~4000 천이 구간, 4000 이상 난류(교과서 공통값: White
  Fluid Mechanics 6장, Çengel Fluid Mechanics 8장).
- 권장 유속 최소 내경 = √(4Q/(π·v최대)). "가장 작은 규격"은 튜브는 같은 단위 목록에서 외경이 가장 작은 것(만족하는 두께 모두 표시),
  배관은 **입력한 두께를 모든 호칭에 같게 보고** 찾는다(화면에 적음).

## 압력손실
- Darcy–Weisbach: ΔP직관 = f·(L/D)·ρv²/2. 100m당 값도 보인다.
- 마찰 계수: 층류(Re < 2300) f = 64/Re. 그 밖은 **Colebrook–White 식을 반복 계산**(Swamee–Jain 값에서 시작, 차이 1e-12까지).
  천이 구간도 Colebrook으로 계산하고(층류 값보다 크게 나와 보수적) 화면에 불확실하다고 적는다.
- Swamee–Jain(1976) f = 0.25/[log10(ε/3.7D + 5.74/Re^0.9)]²은 시험에서 비교용으로만 쓴다. Re 5000~1e8, ε/D 1e-6~1e-2 격자에서
  Colebrook과의 차이는 최대 2.83%(Re 5000·ε/D 0.01), 그 밖은 1.6% 이하. 1/2" 튜브 예제에서는 0.18%.
- 거칠기(mm): 인발 튜브 0.0015, 상용 강관 0.045, 아연도금 강관 0.15, 주철관 0.26, 직접 입력. Moody(1944) ft 값
  (0.000005·0.00015·0.0005·0.00085ft). 확인: Hydraulic Institute Engineering Data Book 표 3.A.1(datatool.pumps.org),
  Pipeflow "Pipe roughness", Engineers Edge(HI·White 7판 인용), Engineering ToolBox. 기본값: 튜브 → 인발 튜브, 배관 → 상용 강관.
  스테인리스 관 값은 출처마다 달라(HI 0.015, Engineers Edge 0.002, Engineering ToolBox 0.0004~0.006) 넣지 않았다.
  HI는 실제 설치 배관에 15%를 더하라고 적는다(화면 값에는 더하지 않음).
- 높이 차: ρ·g·Δz, g = 9.80665m/s²(표준 중력). 출구가 높으면 +.

## 피팅·밸브 K: 3-K 식(Darby)
- K = K1/Re + Ki·(1 + Kd/Dn^0.3), Dn은 호칭 지름(인치). 레이놀즈 수 항이 있어 계기용 튜브의 낮은 유량·기름 층류에서도
  쓸 수 있다(Crane L/D 방식은 완전 난류에서만 맞고 층류에서 K를 작게 잡는다: Darby 2001, katmar).
- Dn: 배관은 호칭(unit_defs.dart의 B 호칭 → 인치), 튜브·내경 입력은 **내경(인치)**. 튜브 외경 규격을 호칭으로 바꾸는 방법은
  어느 출처에도 없어 이렇게 정했다(Dn^0.3이라 영향이 작다).
- 값(원문 Darby "Correlate Pressure Drops Through Fittings", Chem. Eng. 2001년 4월 표 1과 Neutrium "Pressure loss from fittings: 3K method",
  Caleb Bell fluids fittings.py 세 곳 일치):

| 피팅 | K1 | Ki | Kd |
|---|---|---|---|
| 90° 엘보(나사, 표준 r/D 1) | 800 | 0.14 | 4.0 |
| 90° 롱 엘보(r/D 1.5) | 800 | 0.071 | 4.2 |
| 45° 엘보(나사, 표준) | 500 | 0.071 | 4.2 |
| 티 직진(나사) | 200 | 0.091 | 4.0 |
| 티 분기(나사, 엘보로 씀) | 500 | 0.274 | 4.0 |
| 볼 밸브(풀 포트 β = 1) | 300 | 0.017 | 4.0 |
| 게이트 밸브(β = 1) | 300 | 0.037 | 3.9 |
| 글로브 밸브(표준) | 1500 | 1.7 | 3.6 |
| 스윙 체크 밸브 | 1500 | 0.46 | 4.0 |
| 리프트 체크 밸브 | 2000 | 2.85 | 3.8 |

- 볼 밸브 Kd는 원문 4.0, Neutrium·fluids 3.5로 달라 큰 값(원문)을 썼다. K 차이 약 10%(K가 0.08 안팎이라 영향이 작다).
- 티 직진(플랜지) Ki는 원문 0.017이 오타(정오표 0.05, cheresources katmar 글)라 헷갈려 넣지 않았다. 나사 값만 쓴다.
- 체크 밸브 값은 완전히 열린 상태다. Darby는 완전히 열리는 최소 유속(스윙 35·ρ^−½, 리프트 40·ρ^−½ ft/s, ρ lbm/ft³)을 적는다.
  이보다 느리면 K가 더 크다(화면에는 계산하지 않음).
- 관 입구(각진 입구) 0.5, 관 출구 1.0: Crane TP-410 A-30쪽(Fike TB8102 예제 인용), simupipe K 표, fluids.
- 튜브 압축 피팅(유니언 엘보·티)의 K·Cv는 제조사(Swagelok 등)가 공개한 자료를 찾지 못했다. 같은 모양의 나사 피팅 값으로 계산하고
  화면에 대략의 값이라고 적는다. 니들 밸브·버터플라이 밸브도 두 출처 값이 없어 "기타 K"로 넣게 했다.
- 비교로 본 Crane L/D(90° 엘보 30, 45° 16, 티 직진 20·분기 60, 볼 3, 게이트 8, 글로브 340, 스윙 체크 100, 리프트 체크 600)는
  모든 출처가 같지만 곱하는 fT 표가 판마다 다르다(1988판 1" 0.023, 2009판 25mm 0.022). 그래서 3-K를 골랐다.
  Katmar는 어느 방법이든 K를 ±25~30%로 보라고 적는다.
- Cv → K(기타 K 안내): K = 891·d⁴/Cv²(d 인치, Crane TP-410 Cv = 29.9·d²/√K), Val-Matic 890, fluids(ISA-75.01.01) 890.1.
  d를 mm로 쓰면 891/25.4⁴ = 0.00214.

## 기체 압력손실 판정
- 입구 **절대** 압력 대비 ΔP: 10% 미만이면 밀도를 일정하게 본 Darcy 계산을 쓸 수 있다. 10~40%는 입구·출구 평균 밀도로 다시
  계산해야 하고(화면은 입구 밀도 값이라고 적음), 40%를 넘으면 압축성 유동 계산이 필요하다(결과 빨갛게).
  출처: Crane TP-410(LMNO Engineering "Weymouth" 쪽에 인용), Pipe Flow Expert 검증 문서(같은 10%·40% 경계).
- 기체 유속·Re는 입구 압력 기준이다. 하류로 갈수록 압력이 내려가 유속이 빨라진다(화면에 적음).
- 출구 압력(게이지) = 입구 절대 압력 − ΔP − 101.325kPa를 참고로 보인다(40%를 넘으면 보이지 않음).

## 차압 유량계
### 차압 환산
- Q = Qmax·√(ΔP/ΔPmax), ΔP = ΔPmax·(Q/Qmax)². 차압 25% = 유량 50%, 50% = 70.71%.
  출처: instrumentationtools "Square root characteristics of differential pressure flow meters", automationforum
  "Why square root is used in flow measurement", 그리고 아래 ISO 식에서 qm ∝ √ΔP(C 변화 무시).
- 환산표: 유량 % 기준(0·25·50·75·100% → 차압 0·6.25·25·56.25·100%) 또는 차압 % 기준. mA는 차압 비례 출력
  4 + 16·ΔP%/100(계기 교정 화면과 같은 관계), 결과에는 제곱근 출력 설정의 mA(4 + 16·Q%/100)도 보인다.
- 차압 약 1% 아래 저유량 구간은 제조사 설정에 따라 달라 계산하지 않는다(docs/4-20mA계산기_근거.md와 같은 안내).

### ISO 5167-2:2003 오리피스(액체, ε = 1)
원문은 유료라 직접 대조하지 못했고, 원문을 옮긴 2차 출처 여러 곳이 같은 식을 적은 것으로 확인했다.
- 질량 유량 qm = C/√(1−β⁴)·ε·π/4·d²·√(2·ΔP·ρ), β = d/D. 출처: Wikipedia "Orifice plate"(ISO 5167-1 인용), Caleb Bell
  fluids 라이브러리 flow_meter.py.
- Reader-Harris/Gallagher 식(5.3.2.1): C = 0.5961 + 0.0261β² − 0.216β⁸ + 0.000521(10⁶β/ReD)^0.7 + (0.0188 + 0.0063A)β^3.5(10⁶/ReD)^0.3
  + (0.043 + 0.080e^(−10L1) − 0.123e^(−7L1))(1 − 0.11A)β⁴/(1−β⁴) − 0.031(M2' − 0.8M2'^1.1)β^1.3, A = (19000β/ReD)^0.8,
  M2' = 2L2'/(1−β). D < 71.12mm면 + 0.011(0.75 − β)(2.8 − D/25.4). 탭: 코너 L1 = L2' = 0, D·D/2 L1 = 1·L2' = 0.47,
  플랜지 L1 = L2' = 25.4/D(mm). 출처 세 곳 일치: Wikipedia, fluids 소스·문서, Deltares Wanda 문서(multicalci는 식 본체만).
  주의: Wikipedia의 "71.2mm"는 오타(71.12mm = 2.8in), fluids 설명문의 "0.11"은 오타(코드와 Wanda는 0.011).
  fluids에는 ReD 약 3700 아래에서만 값이 바뀌는 ISO 밖 보정이 있어 넣지 않았다(적용 범위 안에서는 같음).
- C는 ReD에 따라 바뀌므로 C = 0.6에서 시작해 ReD → C를 되풀이한다(1e-12까지).
- 적용 한계(5.3.1): d ≥ 12.5mm, 50 ≤ D ≤ 1000mm, 0.1 ≤ β ≤ 0.75, 코너·D·D/2 탭은 β ≤ 0.56이면 ReD ≥ 5000,
  β > 0.56이면 ReD ≥ 16000β², 플랜지 탭은 ReD ≥ 5000이면서 ReD ≥ 170β²D. 벗어나면 결과를 빨갛게 하고 항목을 적는다.
  출처: fluids 문서, simupipe orifice plate, multicalci. 관 거칠기 한계 표는 확인하지 못해 넣지 않았다.
- C 불확도(5.3.3.1): 0.2 ≤ β ≤ 0.6은 0.5%, 0.6 < β ≤ 0.75는 (1.667β − 0.5)%. 출처: simupipe, Emerson Rosemount 기술 노트
  00840 표 6. β < 0.2, D < 71.12mm, β > 0.5·ReD < 10000에서 더하는 값은 한 출처뿐이라 그 경우 불확도를 보이지 않는다.
- 영구 압력손실(5.4): Δϖ = (√(1−β⁴(1−C²)) − Cβ²)/(√(1−β⁴(1−C²)) + Cβ²)·ΔP. 출처: fluids dP_orifice, simupipe, multicalci.
- 시험에 넣은 공개 예제: simupipe(D 100·d 50·플랜지·10kPa·물 20°C → 19.84m³/h, ReD 69,917, C 0.60711, 손실 7.32kPa),
  fluids C_Reader_Harris_Gallagher(D 0.07391·d 0.0222·ρ 1.165·μ 1.85e-5·0.12kg/s·플랜지 → 0.5990326277163659),
  fluids dP_orifice(D 0.07366·d 0.05·ΔP 17kPa·C 0.61512 → 9069.4747Pa). 모두 맞는다.
- 기체·증기(팽창 계수 ε), 노즐·벤투리(ISO 5167-3·4)는 넣지 않았다.

## 유량계 점검 (flow_meter_check.dart, 2026-09-26)
사용자 요청: 유량 전송기 명판 정보(측정 범위·출력 방식)를 넣고, 설치·루프 점검 때 잰 루프 전류(mA)와 표시창·DCS 지시값이
맞는지 본다. 종류는 차압식·전자식·와류식·터빈·질량식, 읽는 값은 루프 mA와 지시값(사용자 선택).
- mA ↔ %: mA = 4 + 16 × % / 100(계기 교정과 같은 식, instrument/signal_calc.dart). NE43 구간도 같은 함수를 쓴다.
- 차압식: 유량은 차압의 제곱근에 비례(ISO 5167-1, 이 문서 "차압 유량계" 절). 전송기 출력이 제곱근(SQRT)이면 mA가 유량에
  비례하고 DCS는 선형으로 받는다. 차압 그대로(LINEAR)면 mA가 차압에 비례하고 DCS·지시계에서 제곱근을 한다. 제곱근은 한 곳에서만.
  Rosemount 3051 설명서(Transfer function: Linear / Square root), 요꼬가와 EJA 설명서(Output mode: Linear / SQRT)에 같은 두 설정이 있다.
- 전자식·와류식·터빈·질량식: mA가 유량에 선형. 양방향 전자식은 하한이 음수일 수 있다.
- 지시값 점검: 차이를 스팬 %와 지시 %로 보이고, 허용오차(스팬 %)는 사용자가 넣을 때만 판정한다(앱 기본값 없음, 계기 교정과 같음).
- 흔한 잘못 찾기: 지시값이 기대값과 안 맞을 때(허용오차, 없으면 스팬 1% 밖) 아래와 맞으면 알려 준다.
  mA가 유량인데(SQRT·선형 계기) 지시값이 10√(출력 %)와 맞으면 "제곱근 두 번", mA가 차압인데(LINEAR) 지시값이 출력 %와 맞으면
  "제곱근 안 함". 범위가 다른 경우(예: DCS 0~120)는 제곱근 탓으로 돌리지 않는다.
- 소유량 차단(Low flow cut-off): 값은 계기·DCS 설정마다 달라 사용자가 넣는다. 그 아래는 0 표시를 정상으로 본다.
- 시험: test/flow_meter_check_test.dart, test/flow_calc_page_test.dart "유량계 점검".

## 넣지 않은 것
- 증기: 포화 증기 밀도는 NIST·Engineering ToolBox가 0.05% 이내로 맞지만 점도는 두 출처가 약 2%까지만 맞고, 과열 증기는 표가 더 필요해 넣지 않았다.
- 배관 스케줄 두께 표(unit_defs.dart 표에 없음), 스테인리스 관 거칠기, 공기 압축 계수.
