## 6. 뒤에 정한 것 (2026-10-12, 사용자 답)

- 표에 없어 정했던 **1홀/2홀 러그**, **볼트 틈새 홀**: 사용자 "좋다" → 그대로 확정.
- **형강 브라켓도 "홀"로 맞춤**: 화면·경고·도움말·결과 표·카톡 글·부재도 글의 "구멍"을 "홀"로(기둥 홀·가로대 홀·전산볼트 홀·앵커 홀·첫 홀·홀·판 탭·둥근 홀 등). 같이 쓰는 "내 펀치 금형" 창도 "홀 지름 칩"으로. 자료 검색은 브라켓에 "홀"·"구멍" 둘 다 찾는 말로 넣음.
- 트레이 가공은 계속 제외(지금 말 그대로).
- 다른 화면(축 정렬·공학용 도구·현장 자료 등)의 "구멍"은 이번에 안 바꿈.
- **부스바 절곡 종류 (10-13)**: 사용자 "ㄱ자 ㄷ자는 뭐지" — 모양 이름(ㄱ·ㄷ)은 90°일 때만 맞아 45°로 두면 "ㄱ자"인데 그림은 ㄱ이 아니었다. 사용자가 "횟수로" 고름: ㄱ자 → **1회 절곡**, ㄷ자 → **2회 절곡**, Z자 (오프셋) → **오프셋**, 연속 절곡 그대로. 도움말에 "(90°면 ㄱ자)·(90°면 ㄷ자)·(Z자)"를 붙여 둠. 메뉴 설명 "1회·2회·오프셋·연속 절곡 전개 길이와 절곡 시작선", 검색은 ㄱ자·ㄷ자·오프셋으로도 찾힘. 철판 가공·브라켓의 ㄱ자·ㄷ자(모양 이름)는 그대로.
