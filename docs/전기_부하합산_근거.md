# 전기 설계 계산 "부하 합산" 근거 (2026-09-27)

파일: `lib/src/presentation/electrical/elec_load_sum.dart`(계산·저장 모양), `elec_load_sum_tab.dart`(화면), `elec_load_sum_pdf.dart`(부하 계산서 PDF).
시험: `test/elec_load_sum_test.dart`.

**전체 상태: 원문 대조 전(2차 자료).** 아래 식과 용어는 국내 전기 설계 자료에서 통용되는 식이고, 한국전기설비규정(KEC)·건축전기설비설계기준 조항 번호로 대조하지 않았다. 웹 검색 결과 요약과 강의·기술 자료 페이지로만 확인했다.

## 식

| 항목 | 식 |
|---|---|
| 줄별 최대수요 유효전력 P [kW] | 설비용량 [kW] × 수용률 |
| 줄별 최대수요 무효전력 Q [kvar] | P × tanφ (φ = acos 역률) |
| 줄별 피상전력 S [kVA] | √(P² + Q²) = P ÷ 역률 |
| 최대수요 kW·kvar | ΣP, ΣQ |
| 최대수요 kVA | √((ΣP)² + (ΣQ)²) |
| 종합 역률 | ΣP ÷ 최대수요 kVA |
| 필요 변압기 용량 [kVA] | 최대수요 kVA ÷ 부등률 × (1 + 여유) |
| 2차 정격전류 [A] | 필요 용량 [kVA] × 1000 ÷ (√3 × 2차 전압 [V]) |
| 부하율 [%] | 필요 용량 ÷ 선정 용량 × 100 (여유 포함) |
| 판정 | 부하율 100% 이하 합격, 초과 불합격 |

- 국내 실무식 "변압기 용량 = Σ(설비용량 × 수용률) ÷ (부등률 × 역률)"과, 역률이 한 값이면 같은 결과다. 줄마다 역률이 다르면 P와 Q를 따로 합해 kVA를 구하는 쪽이 정확하므로 그렇게 했다(엔진 선택, 예제 2로 손계산 확인).
- 수용률은 0 초과 100 이하, 부등률은 1 이상이다. 부등률이 1 미만이면 수용률과 헷갈린 경우가 많아 "입력 확인"으로 막는다.
- 부하율에 여유를 포함한 이유: 장래 증설분까지 변압기가 견뎌야 하는 값으로 판정하기 위해서다. 여유를 뺀 부하율은 결과 줄에 괄호로 따로 보인다.
- 3상 변압기 2차 전압 선택지 380·440·480 V는 지시 사항이며 화면에서 고른다.

## 확인 출처와 상태

식·용어(수용률·부등률·최대수요전력)를 확인한 곳(모두 2차 자료, 조항 원문 대조 전):
- 현대전기 기술 공식 페이지 "변압기 용량 산정 공식" https://m.cafe.daum.net/hdtr/CrIF/36 (검색 결과 요약으로 확인)
- 다산에듀 수용률의 최대수용전력 https://www.e-dasan.net/boardView?id=explain&idx=171463 (검색 결과 요약)
- 변압기 용량의 결정 https://www.eom.co.kr/3.engineering/2.elec/2.source/2.inline%20cap/2.settlement.htm (열람했으나 수요율 표만 있고 식·표준 용량은 없었다)
- electricalnote 변압기 용량 계산 https://electricalnote.com/transformer-capacity-calculation/ (검색 결과 요약)

부하율 60~80%를 적정으로 보는 설명: "최대 부하가 변압기 정격의 80% 정도 범위에서 결정하는 것이 관례"라는 문장을 검색 요약에서 봤다. 2차 자료 한 곳뿐이라 화면에는 "참고(원문 대조 전)"로만 두고 판정에는 쓰지 않는다.

## 넣지 않은 것 (출처 두 곳이 안 맞거나 확인 못 함)

### 표준 변압기 용량 목록 (다음 표준 용량 선정 기능)
확인을 시도했으나 두 곳 이상 일치하는 원문을 못 찾아 **목록을 코드에 넣지 않았다.** 사용자가 선정 용량을 직접 입력한다.

시도한 것과 결과:
- 웹 검색으로 "3, 5, 7.5, 10, 15, 20, 30, 50, 75, 100, 150, 200, 300, 500, 750, 1000 kVA"라는 목록이 두 번 나왔지만, 둘 다 검색 도구의 요약문이었고 원문 페이지에서 확인되지 않았다. 다산·에듀윌 카페 글에서는 "1 2 3 5 7.5 10 15의 10배수"라는 수열 언급과 "표는 이미지"라는 점만 확인됐다.
- 다른 페이지(eom.co.kr 기준용량 표)는 3상 변압기 30, 50, 75, 100, 125, 150, 200, 250, 300, 350, 400, 450, 500, 600, 750, 1000, 1250, 1500, 1750, 2000 kVA로 위 목록과 다르다(125·250·350·400 등이 더 있다).
- IEC 60076-1 관련 검색 요약은 20 MVA 이하 정격 출력을 ISO 3의 R10 수열(100, 125, 160, 200, 250, 315, 400, 500, 630, 800, 1000 kVA …)에서 고르는 것이 바람직하다고 했다. 국내 목록과 다르다.
- KS C 4317(3 MVA 이하 배전용 유입식), KS C 4311(3 MVA 이하 배전용 건식) 표준 소개 페이지(kssn.net)는 제목만 열렸고 정격 용량 표는 없었다. 참고로 KS C 4306은 검색상 JIS C 4306(6 kV 몰드 배전용 변압기) 계열로 나와, 지시서의 "KS C 4306"이 3상 표준 용량표가 실린 표준인지도 확인하지 못했다.
- HD현대일렉트릭 배전변압기 페이지: 유입 100~50,000 kVA, 몰드 100~20,000 kVA(범위만, 개별 용량 없음). LS ELECTRIC·효성 카탈로그는 열지 못했다.
- KDM 스틸: 3상 건식 15~2000 kVA(범위만).

결론: 국내 원문(KS 본문)이나 제조사 카탈로그 표를 사람이 열어 확인하기 전에는 목록을 쓰지 않는다. 확인되면 `elec_load_sum.dart`에 목록 상수를 두고 "다음 표준 용량" 선정을 붙이면 된다.

### 기본값
- 부하 종류별 기본 역률·수용률은 출처 두 곳 확인이 안 되어 **정하지 않았다.** 기본 역률·기본 수용률 칸은 빈 칸이고, 줄에 값이 없고 기본값도 없으면 "입력 확인"이다.
- 부등률 기본 1.0, 장래 증설 여유 기본 0%는 값이 아니라 "적용 안 함"의 뜻이다.

## 확실하지 않은 점
- 위 식은 실무 통용식이며 KEC·건축전기설비설계기준의 조항 번호로 대조하지 않았다.
- 실제 변압기 용량은 고조파·기동 전류·전압강하 검토 등 이 화면이 다루지 않는 조건도 본다. 최종 선정은 설계 기준과 제조사 자료를 따른다.
- 부하 계산서 PDF는 시험에서 생성(바이트 시작 %PDF, 10 KB 초과)과 미리보기 페이지 열림만 확인했고, 인쇄 모양은 눈으로 확인하지 않았다.
