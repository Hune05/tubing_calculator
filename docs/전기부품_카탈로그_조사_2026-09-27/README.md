# 전기 부품 카탈로그 조사 (2026-09-27)

배치도 "전기" 목록에 넣을 판넬 내부 전기·계장 기기(차단기, 접촉기·계전기, DCS·PLC, 계기·CT·퓨즈 단자)의 정면 치수와 모양을
제조사 카탈로그에서 조사한 원자료다. 에이전트가 웹에서 읽은 값이라 각 파일에 출처(URL·페이지)와 확정 여부가 적혀 있다.

- 확정 = 서로 다른 문서 두 곳 이상이 맞음(같은 제조사의 다른 판·사본이면 "동일 제조사"), 단일 = 한 곳뿐, 못 읽음·못 찾음은 그대로.
- **앱에 넣은 것은 "확정"만이다.** 단일 출처·충돌 값은 사용자가 고르기 전에는 넣지 않는다.
- 판넬(캐비닛) 부속(팬·필터·히터·덕트·글랜드·조명·접지 바)은 사용자 요청(2026-09-27)으로 넣지 않는다. panel_aux.md·domestic_aux.md는 참고용으로만 둔다.
- 국내 자료가 빈 곳: 삼화·LS 계기·CT, HD현대 최신 카탈로그(2602판, 내려받기 막힘), 하웅 덕트, 협성 글랜드.

앱 반영: lib/src/presentation/my_work_logs/models/elec_presets_breakers.dart (차단기), 이후 묶음은 같은 폴더의 elec_presets_*.dart.
