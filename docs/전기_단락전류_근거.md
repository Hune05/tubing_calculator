# 전기 설계 계산 "단락 전류" 탭 근거 (2026-09-27, 10-06 원문 대조 반영)

구현: `lib/src/presentation/electrical/elec_short_circuit.dart`(계산), `elec_short_circuit_tab.dart`(화면), 시험 `test/elec_short_circuit_test.dart`.
대상: 저압(1kV 이하) 3상, 구리 도체, 발전기 근처가 아닌 단락(변압기·계통에서 먼 단락). 사용자에게 보이는 글은 한국어.

## 확인 수준 (먼저 읽을 것)

**2026-10-06 원문 대조.** IEC 909:1988을 글자 그대로 옮긴 인도 표준 IS 13234:1992(무료 공개본, https://law.resource.org/pub/in/bis/S05/is.13234.1992.pdf)와 KEC 2026(국가법령정보센터, 공고 제2025-227호)으로 아래를 맞춰 봤다. 조항 번호는 1988판(= IS 13234) 번호다.

**원문을 못 본 것(2016판 유료):** 전압 계수 c(cmax 1.05·1.10, cmin 0.95)와 변압기 보정계수 KT = 0.95·cmax/(1 + 0.6·xT)는 IEC 60909-0:2016 값이라는 2차 자료(pandapower 논문, phasetophase, ECalPro, mycableengineering)만 봤다. 값은 그대로 두었다. 참고로 1988판 표 I은 230/400V가 cmax 1.00·cmin 0.95, 그 밖의 저압이 cmax 1.05·cmin 1.00으로 지금 값과 다르다. 2026-07-23에 IEC 60909-0 3.0판이 나왔으나 보지 못했다.
화면 "근거 보기"에도 "원문 대조함"(출처와 함께)과 "원문 못 봄(2016판 유료)"을 나눠 적었다.
처음 만들 때(09-27)는 서로 다른 출처 두 곳 이상이 같은 값을 말한 것만 넣었다. 그 2차 자료 목록은 아래 "출처 주소"에 남긴다.

## 방식 선택

| 방식 | 쓰임 | 이 탭에서 |
|---|---|---|
| IEC 60909 등가 전압원법 | c 계수·변압기 보정계수 KT를 쓰는 국제 표준 방식 | **주 방식**(최대·최소·피크) |
| %임피던스법 | 공칭 전압 그대로, c·KT 없음. Schneider 설치 지침·기술 자료 158이 설명하는 약식 | **비교**(최대 단락 값 옆에 표시) |

"국내에서 흔히 쓴다"는 것은 이번에 출처로 확인하지 못했다. 두 방식의 식과 값을 나란히 보여 주기만 한다. 변압기 단독 무한 전원에서는 %임피던스법이 IEC보다 약 8% 작다(예 A: 27.62 kA 대 30.04 kA). 차단기 선정은 큰 값(IEC)을 기준으로 한다.

## 식

기호: Un 공칭(2차) 전압, S 변압기 용량, Z 임피던스(Ω), c 전압 계수.

1. 변압기 (IEC 60909)
   - ZT = (%Z/100) × Un²/S
   - 부하손 Pcu를 넣으면 RT = (Pcu/S) × Un²/S, XT = √(ZT² − RT²). 안 넣으면 RT = 0, XT = ZT.
   - KT = 0.95 × cmax / (1 + 0.6 × xT), xT = XT ÷ (Un²/S). ZT·RT·XT에 KT를 곱한다. 최소 단락에도 같은 KT(cmax 기준).
2. 상위 계통: Z = c × Un²/S″kQ, X = 0.995 Z, R = 0.1 X. 넣지 않으면 0(무한 전원).
3. 케이블 구간: X = 0.096 Ω/km × 길이/1000 ÷ 병렬수. 구간을 직렬로 더한다.
   - 최대 단락: R = R20 × 편도길이/1000 ÷ 병렬수(20°C, IEC 909 9.1.1.1).
   - 최소 단락: R = R20 × [1 + 0.004 × (θe − 20)] × 편도길이/1000 ÷ 병렬수(IEC 909 9.3.1 식 32). θe는 단락이 끝날 때 도체 온도이며 절연체 단락 최종 온도를 쓴다: PVC 160°C(배수 1.56), XLPE·EPR 250°C(배수 1.92). KEC 표 212.5-1.
4. 전동기(최대 단락만): IrM = kW×1000 / (√3·Un·(효율×역률)), |ZM| = Un/(√3·배수·IrM), XM = |ZM|/√(1 + 0.42²), RM = 0.42 XM(IEC 909 8.3.2.5). 기여 전류 = c × Un / (√3 × |ZM + Zcable|)(케이블이 없으면 c × 배수 × IrM). 총합은 산술 합. 원문 배수는 5(저압 전동기 묶음).
5. Ik″ = c × Un / (√3 × |Z합|). 최대는 c = cmax(1.05 또는 1.10), 최소는 c = cmin(0.95).
6. 최소 단락 2상: Ik2 = (√3/2) × Ik3.
7. 피크: ip = κ × √2 × Ik″ + κM × √2 × Ik″M, κ = 1.02 + 0.98 × e^(−3R/X), R/X는 고장점까지 전체 합(IEC 방법 a). 전동기 분은 저압 전동기 묶음 κM = 1.3(IEC 909 8.3.2.5).
8. 케이블 열 견딤: S = Ik × √t / k, t_max = (k × S / Ik)². 병렬이면 가닥마다 Ik/n. 통과 에너지 비교: 허용 = n² × k² × S².
9. 차단용량: 차단용량(kA) ≥ Ik″ 최대이면 합격. 투입용량은 넣었을 때만 피크 전류와 비교.

## 출처끼리 값이 다른 것

- **전동기 기여 배수**: IEC 909:1988 원문은 저압 전동기 묶음에 ILR/IrM = 5(10-06 원문 대조). 다른 자료는 Schneider EIG 3.5배(전동기 합계가 변압기 용량의 25% 초과일 때), IEEE C37.13 저압 전동기 묶음 4배(검색 요약만 확인), Schneider 기술 자료 158 예 4.8배(케이블 포함 계산). 칸은 비워 두고(앱이 채우지 않음) 화면 도움말에서 원문 값 5를 권한다.
- **전동기를 무시해도 되는 기준**: 원문 IEC 909 식 (13)은 ΣIrM ≤ 0.01 I″k(전동기를 뺀 단락전류의 **1%**)다(10-06 원문 대조). ECalPro 산업용 안내 페이지의 5%는 원문 값이 아니다. 앱은 자동으로 빼지 않고 세 칸이 다 차면 늘 더한다(EIG는 변압기 용량 25% 기준으로 반대로 "포함해야 하는" 기준을 줌).
- **ECalPro 산업용 페이지**는 저압 cmax를 1.10이라 썼다. 다른 네 곳은 허용오차 +6%이면 1.05. 코드는 두 값을 선택지로 준다. 2016판 원문은 못 봤다.
- **온도계수**: 원문 식 (32)는 0.004/°C다(10-06 원문 대조). pandapower 논문 본문 추출의 0.04는 글자 추출 오류나 오타로 본다. 최소 단락은 0.004를 쓰고, 앱의 다른 탭(전압강하 등)은 기존 구리 값 0.00393을 그대로 쓴다.
- **최소 단락 도체 온도**: 원문 9.3.1은 θe를 "단락이 끝날 때 도체 온도"라 한다(10-06 원문 대조). 전에는 절연체 최고 허용온도(70/90°C)를 썼으나 이것은 운전 온도라 최소 단락이 실제보다 크게 나왔다. 지금은 절연체 단락 최종 온도(KEC 표 212.5-1: PVC 160°C, XLPE·EPR 250°C)를 쓴다. 차단기가 그 전에 끊으면 실제 θe는 더 낮아 최소 단락이 조금 커지므로, 이 값은 보호 감도 확인에서 안전 쪽(작은 쪽)이다. 2차 자료의 예는 pandapower 90°C(지중 케이블), 검색 요약의 80°C, EIG의 1.25배 저항(약 84°C 상당) 등이다.
- **케이블 저항 기준**: EIG는 22.5 mΩ·mm²/m(운전 온도 기준)를 쓴다. 앱은 IEC 60228 20°C 표(최대) 값이다. 최대 단락은 EIG 방식보다 크게 나온다.

## 확인하지 못한 것

- IEC 60909-0:2016 원문(유료): 전압 계수 c(cmax 1.05·1.10, cmin 0.95)와 KT 식·적용 조건. 값은 2차 자료 그대로 두었다. 1988판 표 I(230/400V cmax 1.00·cmin 0.95, 그 밖의 저압 cmax 1.05·cmin 1.00)과 다르다. 2026-07-23에 나온 IEC 60909-0 3.0판도 보지 못했다.
- IEC 60364-4-43 표 43A 원문(ANSI 미리보기 403). 같은 k 값은 KEC 표 212.5-1 원문으로 확인했다.
- 300mm² 초과 PVC의 k 103은 KEC 표 212.5-1 원문에 있다(구리 PVC 300 이하 115·초과 103, PVC 90 °C 100·86, XLPE·EPR 143, 고무 141, 무기 115·135 / 알루미늄 76·68·66·57·94·93). 굵기 표가 300mm²까지라 화면에서는 나오지 않는다.
- KEC 조항(10-03 원문 확인): 차단용량 > 예상 최대 단락전류(212.5.5의 1), t = (kS/I)²·5초 이하(식 212.5-1). 한전 수전 단락용량 표준값은 조사하지 않았다. 상위 계통 용량은 사용자 입력이다.
- 한전 저압 전압 허용오차(+6%인지 +10%인지)는 확인하지 않았다. 사용자가 고른다.

## 계산에서 뺀 것 (화면에도 표시)

- 지락(1선) 단락: 영상 임피던스가 필요하다. 화면에 "포함하지 않음"이라고 적었다.
- 발전기 근처 단락(Ib, Ik 감쇠), 비대칭 차단 전류, 아크 저항(EIG는 약 20% 감소라 했으나 안전 쪽이라 뺌), 차단기·부스바 임피던스(EIG 0.15 mΩ 등), 150mm² 이상 표피 효과(EIG 150 +15%, 185 +20%, 240 +25%, 300 +30%는 단일 출처라 미반영이며 최소 단락에서 값이 조금 크게 나옴), 병렬 가닥 상호 리액턴스, 알루미늄 도체, 상위 차단기 한류 효과와 후비 보호, IEC 방법 b·c의 1.15κ 보정.
- 전동기를 케이블 앞(변압기 2차)에 둔 것으로 계산한다. 전동기가 단락점 가까이 있으면 기여가 더 크다.

## 안전 방향 판단 (부하손을 모를 때)

부하손을 비우면 RT = 0으로 둔다. 일반 배전 변압기 여섯 조합(100~2000kVA, 케이블 유무, 계통 유무)을 시험한 결과 RT = 0이 최대 단락을 최대 약 15%, 피크 전류를 최대 약 50% 크게 만들었다(안전 쪽). 최소 단락도 같은 방향으로 크게 나와 안전 쪽이 아니다. 시험 `부하손을 모르면 값이 크게 나온다`가 이 방향을 지킨다. 일반화된 증명은 아니므로 화면에도 "시험한 예에서"라고 적었다.

## 케이블 열 견딤 사용 방법

- 케이블 시작점의 Ik″(전류가 가장 큼)로 검토한다. 고장점(끝) 값이 아니다.
- 5초 초과는 표준 적용 범위 밖이라 IEC 60949 계산을 안내한다. 0.1초 미만은 시간보다 제조사 통과 에너지(I²t) 곡선으로 확인하라고 안내하고, 통과 에너지를 넣으면 n²·k²·S²와 비교한다.
- 시간 t는 사용자 입력(차단기 특성 곡선에서 읽은 값). 앱이 차단 시간을 정하지 않는다.

## 손계산 예 (시험에 들어 있음)

- 예 A: 1000kVA, %Z 5.5, 380V, 무한 전원. In = 1519.34 A. %임피던스법 27,624 A. IEC: KT = 0.96563, ZT = 7.942 mΩ, Ik″ = 30,038 A, κ = 2.0, ip = 84,960 A.
- 예 B: 예 A + 240mm² 50m. 20°C R = 3.77 mΩ, X = 4.8 mΩ. %임피던스법 16,511 A, IEC 17,684 A. 최소(XLPE θe 250°C, R = 3.77 × 1.92 = 7.238 mΩ) 3상 14,456 A, 2상 12,519 A. PVC(θe 160°C, × 1.56)면 3상 15,118 A, 2상 13,093 A. (예전 90°C·0.00393 값은 3상 15,596 A였다.)
- 전동기: 200kW, 효율×역률 0.8, 배수 5, 380V, 예 A 조건. IrM = 379.84 A, |ZM| = 115.52 mΩ, XM = 106.51 mΩ, RM = 44.73 mΩ. 기여 1,994.1 A. ip = 2.0 × √2 × 30,038 + 1.3 × √2 × 1,994.1 = 88,626 A.
- 예 C: 500MVA, 부하손 10kW, 95mm² 30m 2병렬 + 16mm² 20m. 구간 시작 28,884 A, 구간 1 끝 22,490 A, 고장점 7,801 A(R/X 2.44, κ 1.0207), %임피던스법 7,395 A.
- I²t: 구리 PVC 95mm², Ik 10kA → t_max = (115×95/10000)² = 1.1936초, XLPE는 1.8456초. 허용 통과 에너지 119,355,625 A²s.

Schneider EIG 예(1000kVA, 5%, 420V, 500MVA, Pcu 13.3kW)와도 방향이 맞는지 보려 했으나 EIG는 저항에 22.5 mΩ·mm²/m(운전 온도), c와 KT 없음, 전압 420V를 써서 값이 직접 맞지 않는다. 시험에는 넣지 않았다.
