# 전기 설계 계산 "접지"·"전동기 보호" 탭 근거 (2026-10-03)

## 확인 수준 (먼저 읽을 것)
- 모든 값은 웹 조사로 확인했고 **KEC 원문(법제처·협회 PDF)은 직접 열지 못했다.** KEC 조문은 사설 옮김 사이트(cq4l.com, 2024-05 판)와
  기술사 풀이 사이트, 일렉킴(2026-01-06 개정 142.3.1 인용)으로 확인했다. 앱에 쓴 값은 서로 다른 두 곳 이상이 같은 것만이고,
  한 곳뿐이거나 출처끼리 달랐던 값은 "참고·범위"로 표시했다. 원문 대조 전 값이다.
- 앱 화면의 "근거 보기"에도 같은 내용을 적었다.

## 접지 탭 (`ground_calc.dart`, 화면 `elec_ground_tab.dart`)
| 항목 | 값·식 | 확인 |
|---|---|---|
| 보호도체 표 142.3-1(구리, 선도체와 같은 재질) | S ≤ 16 → S, 16 < S ≤ 35 → 16, S > 35 → S/2 | 2곳 이상(cq4l·Sorivo·전기저널) |
| 보호도체 단열 식 | S = √(I²t) / k (t ≤ 5초) | 2곳 이상 |
| k 값(IEC 60364-5-54 부속서 A) | 따로 포설 구리 PVC 143·XLPE 176, 알루미늄 PVC 95·XLPE 116 / 케이블 안·묶음 구리 PVC 115·XLPE 143, 알루미늄 PVC 76·XLPE 94 | Legrand·Sorivo·elec-mate 일치. 강 PVC는 52(Legrand)·51(BS) 달라 넣지 않음. 나도체 k 못 구해 뺌 |
| 접지도체 최소 | 구리 저압 6·고압 이상 16 mm², 철 50, 알루미늄 불가 | 일렉킴(2026-01-06 개정) + 검색 요약 일치. 2024 판은 "큰 고장전류가 없을 때 구리 6·철 50"이라 개정 확인 필요 |
| 중성점 접지저항 KEC 142.5 | R ≤ 150/I₁, 혼촉 저압 150 V 초과·1~2초 차단 300/I₁, 1초 이내 600/I₁ | 2곳 이상(cq4l·eom·hioki) |
| TT 누전차단기 | R_A × IΔn ≤ 50 V(교류) / 120 V(직류) | 2곳(cq4l·전기저널) |
| 본딩 도체(구리) | 가장 큰 보호도체의 1/2 이상, 6 mm² 이상, 25 mm² 넘길 필요 없음 | cq4l 한 곳 + 전기저널 요약 |
| 접지봉 1본 | R = ρ/(2πl)·(ln(4l/r) − 1) | **eom 한 곳**. 근사식. 화면에 "근사·한 곳 자료" 표시 |
| 봉 병렬 | R_n = K·R₁/n, K = 1.2(간격 1~10 m), 1.0(10 m 초과), 1 m 미만 불가 | eom 한 곳 |
| 대지저항률 참고 | 늪지 30, 농경지·점토 100, 사질 점토 150, 습한 모래 300, 습한 자갈 500, 건조 모래·자갈 1000 Ω·m | HIOKI와 기술사 풀이가 대략 일치. 출처마다 폭이 커서 "참고"만 |
| 3점 전위강하법 | C극 접지극 규모 6.5배 이상(또는 80 m 이상), P극 61.8 %, 51.8·71.8 %로 확인 | 2곳(ftz·eom) |

**넣지 않은 것**: TT 100 Ω 상한과 고압·특고압 접지저항 제한(개정안 단계 보도뿐, 시행 여부 못 확인), 접촉·보폭 전압 IEEE 80 식(한 곳),
접지 격자·메시 식, 나도체 k, 판·링 접지극 식.
