# 자료 검색 "압력시험 누설"·"계기 신호 진단" 근거 (2026-10-03)

## 확인 수준
- 압력시험: Swagelok 설치 자료, ABSA AB-522, EIGA Doc 254/26, PPI TN-46 등 원문을 열람한 내용만 썼다. 독립 출처 기준으로는 한 곳인 항목이 많다(Swagelok 피팅).
- 못 구한 것: Parker·Hy-Lok 자료, KEPCO 사내 기준, KGS 코드 원문, ASME B31.3/B31.1/PCC-2 원문(유료). 밸브 스템·패킹, 용접부 결함 누설 자료는 신뢰할 출처를 못 찾아 넣지 않았다.
- 일부러 수치를 뺀 것: 물의 온도당 압력 변화(출처별 0.6~100 psi/°F로 상이), 기체 "5 psi/°F"(이상기체 계산과 24배 차이), PCC-1 볼트 단계 비율(사이트별 상이), PPI 3~24시간 대기(HDPE 기준).
- 코드는 "누설 없음"을 요구하고 허용 압력 강하 %는 정하지 않는다(B31.3, 2차 해설로 확인. 원문 미확인).
- 계기 신호: NE43 범위, 루프 부하 식, Pt100 값은 여러 곳 일치. 송신기 최소 전압·번아웃 기본 방향은 기종 사양서 확인으로 남겼다. 스위치·접점 신호 진단은 조사하지 않았다.
- 열람이 아니라 요약으로만 본 항목이 섞여 있으니 현장 적용 전 설명서와 대조할 것.
