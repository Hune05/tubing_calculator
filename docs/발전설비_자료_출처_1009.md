# 발전 설비 탭 자료 출처 (2026-10-09)

현장 자료 → 발전 설비 탭(`lib/src/presentation/reference/page/ref_plant_tab.dart`)을 "전문 자료로 채워줘"(사용자, 10-09) 요청으로 다시 쓰면서 조사한 기록. 공개 자료만 썼고, 국내(한전KPS·발전교육원·KOSHA) 공개 수치는 찾지 못했다(국내는 KPX 전력시장운영규칙 droop 기준, KHNP 논문 요지뿐).

표시: [일반] 표준·교재·지침 / [OEM] 제작사 특정 / [현장] 특정 발전소 절차서 / [업체] 계측기·설비사 / [불확실] 원문 미확인.

## 예전 글에서 틀렸던 것
- 씰 오일 진공 탱크: "수소 쪽 오일의 녹은 수소를 진공으로 뽑는다" → 실제는 씰로 보낼 오일의 공기·수분 제거(수소 순도 유지). 수소측 배유는 detraining tank → loop seal·float trap.
- "발전기가 멈춘 뒤에도 한동안" 씰 오일 유지 → 케이싱에 수소가 있는 동안은 계속(정지·터닝 중에도).
- 가스 판넬 "순도(수분·불순물 비율)" → 순도(H₂ %)와 노점(수분)은 별개.
