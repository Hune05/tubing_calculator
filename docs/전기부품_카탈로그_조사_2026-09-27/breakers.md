# 저압 차단기 정면 치수·모양 조사 (2026-09-27)

읽기 전용 조사. 앱 파일은 건드리지 않음. 단위 mm. 가로(W)×세로(H)×깊이(D).
깊이 D = 설치 면에서 본체 앞면까지(손잡이 제외)를 뜻하도록 적었으나, 카탈로그마다 기준이 조금 달라 각 줄에 도면 표기를 함께 적음.
표기: **확정** = 서로 다른 문서 2건 이상 일치 / **단일** = 한 곳뿐 / **못 읽음** = 자료는 있으나 값을 못 읽음 / **못 찾음**.
같은 제조사의 서로 다른 문서(도면+리플릿)는 "확정(제조사 문서 N건)"으로 적음. 유통사 요약 글은 참고로만 세고, 그렇게 센 곳은 표기함.
검색 도구 한도(200회)가 소진되어 뒤쪽 업체(Emax 2, 3WL, IZM, Susol ACB, 상도·대륙)는 조사하지 못함.

기억으로 쓴 값은 없음. 아래 값은 전부 내려받은 문서에서 읽거나 검색 결과에서 그대로 옮긴 것.

## 3. 정면 모양 특징

A. LS Susol TS (도면 A-6-4~6, S1)
- 정면 가운데에 세로 홈 하나짜리 손잡이 창. 손잡이 위아래로 ON/OFF 글자. 창 높이 도면 표기: TS250 약 60, TS630 약 71, TS800 약 82.8(도면 글씨가 작아 불확실).
- 손잡이 창 아래에 명판·트립 유닛 띠. 눈금 다이얼이 두 개, 왼쪽 아래 "Trip button" 지시선이 걸린 작은 단추.
- 위·아래에 단자 나사 3쌍(4P는 4쌍). 위쪽에는 절연 격벽이 튀어나옴(TS250에서 50 돌출).
- 4P는 왼쪽에 큰 "N" 글자와 검은 환기 슬릿 띠(4P R형은 N이 오른쪽).
- 장착 구멍: TS250 3P 세로 125 간격, 가로 35+70, M4 또는 φ5. 문 구멍 107×102(3P), 142×102(4P).

B. ABB Tmax XT (사진 S6 p.3)
- 검정 본체. 맨 위에 흰 글씨 명판 띠(표가 인쇄됨).
- 정면 가운데에 흰회색 토글. 왼쪽 "I / ON"(빨강 띠), 오른쪽 "O / OFF"(초록 띠). 위쪽 빨간 판에 ABB SACE Tmax 로고.
- 왼쪽 위에 분홍 원형 위조방지 마크. 오른쪽 아래 둥근 TEST 단추. 맨 아래 줄에 트립 유닛(I1, I3 눈금 다이얼) 띠.

C. 슈나이더 NSX (S8 p.6 작은 사진, 판독 한계)
- 검정 본체, 아래쪽에 밝은 파란 띠(트립 유닛 부분)로 보임. 정확한 배치는 못 봄.

D. 지멘스 3VA (LV 10 사진)
- 슬레이트 회색 본체, 가운데 손잡이, 그 아래 트립 유닛. 큰 프레임(3VA25 이상)은 손잡이가 더 크고 아래에 전자식 유닛이 붙음. 두께가 얇음(70). 정확한 색·명판 위치는 사진이 작아 못 읽음.

E. MPCB
- ABB MS132: 폭 45, 가운데 둥근 회전 손잡이(ON/OFF/TRIP 표시), 위아래 나사 단자, 옆면 리브. DIN 레일용(도면 S17).
- 슈나이더·지멘스: 사진을 못 봄. 값만 있음.
