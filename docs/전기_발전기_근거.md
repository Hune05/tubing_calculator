# 전기 설계 계산 "발전기 용량" 탭 근거 (2026-09-27, 2026-10-06 원문 대조 반영)

파일: `lib/src/presentation/electrical/elec_generator.dart`(PG 방식 계산), `elec_generator_gp.dart`(GP 방식 계산), `elec_generator_tab.dart`(화면), `test/elec_generator_test.dart`·`test/elec_generator_gp_test.dart`(시험), `test/elec_crosscheck_test.dart`(독립 대조).

GP 입력(2026-10-07): 전동기 이외 부하는 줄 목록(최대 20줄)으로 넣는다. 줄마다 종류(일반 식 4.1-2 / VVVF 전동기 식 4.1-4 / LED 등 고조파 부하 식 4.1-5)·kW·효율·역률을 따로 넣어, 부하마다 효율·역률이 달라도 원문 식대로 줄마다 나눠 더한다(예전에는 세 칸이 효율·역률 하나를 같이 썼다). 예전 저장값(일반·VVVF·LED 칸과 같이 쓰던 효율·역률)은 처음 열 때 줄로 옮긴다. UPS와 λ는 따로 한 칸이다. 표 4.1-1 칸을 누르면 그 칸(허용 전압강하 %, x″d %)을 함께 남겨 결과에 "k 1.00: 표 4.1-1에서 허용 전압강하 20 %, x″d 25 % 칸을 고른 값입니다."로 적고, k를 손으로 고치면 "직접 입력한 값"으로 적는다.

## PG 방식

원문 3.1.2(1): PG 방식은 부하에 사이리스터 부하가 포함되지 않은 경우에 쓴다. 필요 발전기 용량 = PG1, PG2, PG3 중 큰 값[kVA].

| 이름 | 원문 식 | 뜻 |
|---|---|---|
| PG1 | ΣPL × DfL ÷ (ηL × cosθL) | 정상 운전 부하에 급전 |
| PG2 | Pm × β × C × xd″ × (1 − ΔV) ÷ ΔV | 가장 큰 전동기 기동 시 허용 순간 전압강하 |
| PG3 | {(ΣPL − Pm) ÷ ηL + (Pm × β × C × Pfm)} × 1 ÷ cosθL | 다른 부하 운전 중 마지막 전동기 기동 |

기호: ΣPL 부하 출력 합계[kW], DfL 수용률, ηL 부하 종합 효율, cosθL 부하 종합 역률, Pm 기동 용량이 가장 큰 전동기 출력[kW], β 전동기 출력 1kW당 기동 입력[kVA], C 기동 방식 계수, xd″ 발전기 과도 리액턴스(소수), ΔV 허용 순간 전압강하(소수), Pfm 전동기 기동 역률.
xd″·ΔV는 화면에서 %로 받아 100으로 나눈다. 정격전류 = kVA × 1000 ÷ (√3 × V).

### 원문 계수와 화면

| 항목 | 원문 | 화면 |
|---|---|---|
| ηL | 불분명시 0.85 | 기본값 85 % |
| cosθL | 불분명시 0.8. PG1과 PG3에 같은 값을 쓴다 | 기본값 80 % |
| xd″ | 보통 0.2~0.25 | 기본값 없이 입력. 안내에 20~25 % |
| ΔV | 승강기의 경우 20 %, 기타 25 % (3.1.2(4)) | 기본값 없이 입력. 안내에 그대로 |
| Pfm | 불분명시 0.4 | 기본값 40 % |
| C (3.1.1(5) 표) | 직입 1.0, Y-Δ 0.67, 리액터 65 % 0.65, 리액터 80 % 0.80, 콘돌퍼 50 %·65 %·80 % 0.25·0.42·0.64 | 칩 7개 + 직접 입력 |
| β | 기동 계급별: E 6.35, F 7.2, G 8.0, H 9.0, J 10.1, K 11.4 (표 범위의 가운데 값) | 칩 6개 + 직접 입력 |

- 원문 C 표의 리액터 50 %는 65 %와 같은 0.65로 인쇄돼 있다. 오타로 보여 칩에 넣지 않았다.
- β 7.2는 F 계급 값이다. 2차 정리 글에 보이는 "0.72"는 원문 값이 아니다(틀린 옮김).
- 입력 확인: X″d·ΔV 칸은 %라서 0.25처럼 비율을 넣으면 0.25 %로 계산되니 고쳐 읽지 않고 "입력 확인"으로 알린다.

### 2026-10-06에 원문 대조로 고친 것
1. PG3를 따로 받던 "발전기 역률"로 나누던 것을 원문대로 부하 종합 역률 cosθL로 나눈다. 발전기 역률 칸(`eg_genpf`)을 없앴다.
2. 고조파 가산 PG4(PG1 + Pc × 2.0~2.5)와 고조파 부하·가산 계수 칸(`eg_harm`, `eg_harmf`)을 없앴다. 원문에 PG4는 없다. 원문은 사이리스터(고조파) 부하가 있으면 PG 방식을 쓰지 않는다(3.1.2(1)). 그런 부하는 원문의 RG 방식(앱에 없음)이나 현행 GP 방식으로 계산한다. 결과 칸에 "고조파(사이리스터) 부하가 있으면 PG 방식을 쓰지 않습니다(원문 3.1.2(1)). 위 "GP 방식"을 쓰십시오."를 항상 보인다.
3. 기동 역률 기본값 40 %(원문 불분명시 0.4).
4. C 칩에 리액터 80 %, 콘돌퍼 50 %·65 %·80 %를 더했다.
5. β 기동 계급 칩(E~K)을 더하고 "0.72" 안내를 뺐다.
6. ΔV 안내를 원문대로(승강기 20 %, 그 밖에 25 %) 고쳤다. "비상용", "이하"는 원문에 없다.

### 예전에 참고한 2차 자료 (지금은 원문으로 대체)
- KIEE 논문 2018 "비상발전기용량 산정식 개선에 관한 연구"(이종혁·김진오, Trans. KIEE 67(11) 1517-1522). 예제 PG2 = 75 × 7.2 × 0.65 × 0.25 × 0.8 ÷ 0.2 = 351 kVA는 원문 식으로도 같다.
- cq4l.com "발전기 용량 산정방식": PG3를 발전기 역률 cosθG로 나누고, PG4 = PG1 + Pc × (2.0~2.5), β 0.72로 적었다. 셋 다 원문과 다르다.

## 기본값과 입력 칸 (PG 방식)
- 기본값으로 채운 것: 수용률 100 %(중립), 효율 85 %, 역률 80 %, 기동 역률 40 %(셋 다 원문 불분명시 값), 발전기 전압 380 V(저압 3상, 사용자가 바꿈).
- 기본값 없이 입력 칸: X″d, ΔV, β(칩으로 채움), C(칩으로 채움).
- 입력 오류(숫자 아님, 범위 밖, 전동기를 넣었는데 β·C·X″d·ΔV 빠짐 등)는 "입력 확인"으로 보이고 조용히 자르지 않는다.

## 확인 못 한 것·넣지 않은 것
- RG 방식(사이리스터 부하가 있을 때의 원문 방식)은 넣지 않았다. 고조파 부하는 GP 방식을 쓴다.
- 단상 부하 불평형 보정, 발전기 고도·온도 출력 감소, 엔진 출력과 발전기 kVA의 관계, 연료·환기·소음 조건, 병렬 운전.
