## 0. 꼭 지킬 것 (어기면 안 됨)

1. **설명·보고·커밋 메시지는 한국어로만.** 화면 글은 습니다/십시오 체, 현장 말(잔재·곤질레다·커플링…). 내가 지은 말 금지.
2. **벤딩 계산 엔진(마킹 값) 건드리지 않기.** `tube_bending_engine.dart`, 전선관 마킹 셈, `bend_path.dart`. 테스트 기준값이 바뀌는 수정은 하지 않는다.
3. **진짜 자료 보호.** 폰의 루마·H2(튜브), 전선관(형강), 잔재 목록, 서버에 저장된 배치도("현장 레이아웃_22일" 등)는 절대 고치지 않는다.
   시험은 임시 저장(이어하기)으로만 하고, **시작 전 prefs 백업 → 끝나면 되돌리고 md5 비교.**
4. **폰에서 보내기·공유·로그인·결제·"한 번만/항상" 고르기는 누르지 않는다.** 공유 창에 카톡 대화방이 뜨면 뒤로 가기.
5. **사용자가 폰을 쓰는 중이면 손 뗀다.** 설치·강제 종료 전에 화면을 두 번(5초 간격) 찍어 바뀌는지 보고, 앱 화면이 움직이면 설치를 미룬다.
6. `dart format`은 고친 파일만. `git add`는 파일 이름을 적어서(`.claude/`는 올리지 않음). 커밋 끝에 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
7. 일 하나 끝날 때마다: `dart analyze lib test` → `flutter test`(전부 통과) → APK 빌드(`. tool/keys.local.sh && flutter build apk --debug --dart-define=KAKAO_REST_KEY=$KAKAO_REST_KEY`) → 폰 확인(가능하면) → 커밋 → push.

## 1. 미리 정해 둔 것 (묻지 않는다)

- 스키드 정면·측면: 부품은 평면에 하나(평면 기준). 보는 쪽에서 가까운 부품을 위에, 가까운 부품에 가려지는 뒤 부품은 **흐리게**(도면의 숨은선처럼). "가려진 부품 숨기기"를 켜면 가려진 것은 안 그린다. 기본은 흐리게.
- 앞·뒤 기준: 정면 = 평면 아래쪽(y 큰 쪽)에서 본다, 좌측면 = x=0 쪽, 우측면 = x 큰 쪽(좌우 뒤집어 그림). 지금 셈과 같다.
- 곤질레다 치수는 대략 값 그대로(사용자가 실물 재서 알려 주기로 함). 새 치수를 지어내지 않는다.
- 새 단추·메뉴 이름이 필요하면 앱에 이미 있는 말을 쓴다. 이미 있는 말이 없으면 만들지 않고 "아침에 물을 것"에 적는다.

## 2. 할 일 (위에서부터 차례로)

### A. 스키드 정면·측면: 그쪽에서 보이는 것만 보이게 (먼저)
- 문제: 지금은 평면 부품이 모두 같은 진하기로 겹쳐 그려져, 뒤쪽 부품과 앞쪽 부품이 구분되지 않는다(엑스레이처럼 보임). 누르면 뒤 부품이 잡힐 수도 있다.
- 고칠 것: 보는 쪽에서 먼 것부터 그리기(가까운 것이 위·먼저 잡힘), 가까운 부품과 겹쳐 가려지는 뒤 부품은 흐리게, "관리" 창에 "가려진 부품 숨기기" 켜고 끄기(판마다 아니고 도면 하나에 하나, 임시 저장에 남김).
- 완료 기준: 테스트(가까운 것이 위, 가려진 것 흐림/숨김, 좌·우측면 앞뒤가 반대), 폰에서 앞뒤로 겹친 두 부품 확인.

### B. 스키드 남은 것
1. 곤질레다·커플링·유니온 **좌우 뒤집기**(허브가 반대쪽): 편집 칸에 단추. 모양만 뒤집고 크기는 그대로. 저장 칸 하나 추가(예전 도면은 그대로 열려야 함).
2. 정면·측면 **고정 치수 측정**에 평면 부품도 잡히게(그 면에서 본 자리로 잰다). 어렵거나 저장 구조를 크게 바꿔야 하면 건너뛰고 기록.
3. 경로 입력 화면 작은 도면의 점선 네모를 부품 모양으로(SkidPartPainter 재사용).

### C. 앱 전체 점검·정리 (고칠 수 있는 것만)
1. `dart analyze` 경고 없애기(동작이 바뀌지 않는 것만): 안 쓰는 import·함수, 늘 참인 null 비교, if 중괄호 등. info 중 `print`는 `debugPrint`로. 파일 이름 바꾸기(file_names)는 import가 많이 바뀌면 건너뜀.
2. 폰 폭(344dp)에서 넘치는 화면이 있는지 기존 넘침 테스트 범위를 보고, 배치도 새 화면(축척 맞추기·받은 도면 창·스키드 부속 창)에 넘침 테스트 추가.
3. 이번 주에 만든 것 다시 보기(버그만): 축척 맞추기, 카톡 도면 받기(앱 켜짐/꺼짐), 치수 글자 배율, W·H 표기, 스키드 면별 그리기. 찾은 버그는 고치고 테스트로 막는다.
4. 계산 엔진·서버 자료 구조·로그인은 손대지 않는다(찾으면 "아침에 물을 것"에만 적는다).

### D. 후순위(시간 남으면)
