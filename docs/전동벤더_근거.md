# 전동 벤딩 계산기 근거 (2026-09-26)

사용자 요청: "튜브 전동 벤딩기도 장비 목록의 전동 장비 기준으로 계산기를 만들어줘".
사용자 선택(2026-09-26):
- Swagelok 명판은 MS-BTB(벤치탑)입니다.
- TB20D 금형 값은 비워 두고 시험 굽힘으로 채웁니다.
- 기존 "전동 벤딩 계산기"는 새 계산기로 바꿉니다.
- 설정·참고 화면의 틀린 표는 매뉴얼 값으로 바로잡습니다.

코드는 다음과 같습니다.
- `lib/src/presentation/electric_bender/` 아래
  - `electric_machines.dart`: 장비·금형 목록과 저장(`electric_bender_v1`)
  - `electric_bend_plan.dart`: 계산
  - `electric_bender_page.dart`: 화면
  - `electric_machine_guide.dart`: 설정 화면 안내
- 시험: `test/electric_bender_test.dart`

## 벤딩 엔진은 고치지 않았다
- 튜브 벤딩 엔진 `TubeBendingEngine.calculate`와 형상 점검 `checkBends`, `tubeFittedLengths`, `straightAfterLastBend`를 그대로 불러 씁니다.
- 마킹은 엔진과 같이 관이 휘기 시작하는 자리(탄젠트)이고, 길이는 교차점(C-C) 기준입니다.
- 이 화면이 더하는 것은 장비 쪽 값뿐입니다.
  - 넣을 각도(스프링백)
  - 장비 최대 각
  - 클램프 물림 길이, 마지막 다리 최소 길이 경고

## Swagelok MS-BTB (벤치탑 전동)
출처는 다음 두 문서입니다.
- MS-13-145 Bench Top Bender User's Manual: https://www.swagelok.com/downloads/webcatalogs/en/ms-13-145.pdf
- MS-01-179 Tube Fitter's Tools: https://www.swagelok.com/downloads/webcatalogs/en/ms-01-179.pdf

사양은 두 문서가 같습니다.
- 관경은 1/4"~1-1/4", 6~30mm입니다.
- 굽힘 각은 1~180°입니다.
- 각도는 숫자 바퀴(thumb wheel)로 넣고 토글 스위치로 꺾습니다. 풋 페달은 옵션입니다.

벤드 슈 반경(두 문서 3쪽)
| 관경 | 반경 |
|---|---|
| 1/4", 3/8" | 36mm (3/8"는 56mm 슈도 있음) |
| 1/2" | 36mm 또는 56mm |
| 5/8" | 46mm |
| 3/4" | 56mm |
| 7/8" | 67mm |
| 1" | 82mm |
| 1-1/4" | 112mm |
| 6·10·12mm | 36mm |
| 14·15·16mm | 46mm |
| 18mm | 56mm |
| 20·22mm | 67mm |
| 25mm | 82mm |
| 28·30mm | 112mm |

- 마킹 방법(MS-13-145 4쪽): 꼭짓점에서 bend deduction만큼 물러나 bend mark를 긋고, 이 자리를 벤드 슈의 기준선(reference mark)에 맞춥니다.
  bend deduction은 "꼭짓점에서 관이 휘기 시작하는 자리까지"(17쪽)라서 엔진의 마킹과 같은 뜻입니다. 매뉴얼 표 값은 실측이라 몇 mm 다를 수 있습니다.
- 스프링백(14쪽): 한 번 꺾어 잰 차이를 숫자 바퀴에 더합니다. 예를 들어 90을 넣어 86이 나오면 94를 넣습니다. 작은 각은 덜 튀고 큰 각은 더 튑니다.

**넣지 않은 것**
- 매뉴얼의 굽힘 표(bend allowance·deduction·length)와 마지막 다리 최소 길이 표는 넣지 않았습니다.
- 까닭: pdf에서 글을 뽑으면 열이 섞여, 줄과 각도를 믿고 맞출 수 없었습니다. 예를 들어 1/4" 표의 각도 줄 13개 순서가 값 줄과 따로 나옵니다.
- 대신 게인·스프링백은 시험 굽힘으로 채웁니다. 클램프·마지막 다리는 사용자가 매뉴얼 표를 보고 넣는 칸으로 두었습니다.

## TRACTO-TECHNIK TUBOBEND TB20D
출처는 다음과 같습니다.
- 제품 페이지: https://pipe-bending-systems.de/en/semi-automatic-pipe-bending-machines/tubobend-20-2/
- 데이터시트(2021판): https://pipe-bending-systems.de/wp-content/uploads/2023/11/Datenblatt-TUBOBEND-20_EN.pdf

알려진 것
- 반자동입니다. 굽힘 축만 자동이고 이송·회전은 손으로 합니다.
- 각도 8개를 미리 넣고 자동으로 순서를 넘깁니다.
- 옵션: 터치 패널(프로그램 100개), 길이·회전 스토퍼, 굽힘·클램프 풋 스위치.
- 능력은 두 판이 다릅니다. 웹 페이지는 강관 Ø20×2mm·최대 반경 50mm, 2021 데이터시트는 Ø16×2mm·45mm입니다.
- 명판 값(일련번호 286, 2020년)은 설정 화면에 있던 그대로 둡니다.

공개 자료에 없는 것
- 금형별 반경, 클램프 길이, 게인, 스프링백 입력 기능, 최대 굽힘 각
- 그래서 금형 목록은 비워 두었습니다. 사용자가 "금형 더하기"로 금형 각인 R을 넣습니다.
- 계산기는 손 이송 장비라서 "밀기(곧은 부분)·돌리기(굴림)·각도" 한 줄을 함께 보여 줍니다.

## 계산
- **넣을 각도** = 설계각 + 스프링백(θ)입니다.
  - 스프링백(θ) = 스프링백(90°) × θ/90으로 어림합니다.
  - 매뉴얼이 "작은 각은 덜, 큰 각은 더 튄다"고 적은 것을 비례로 어림한 것이라 화면에 "어림"이라고 적습니다.
- **시험 굽힘**
  - 게인은 기존 `gainFromMeasured`로 구합니다(두 다리 합 − 자른 길이, 나온 각도로 90° 환산).
  - 스프링백(90°)은 (넣은 각 − 나온 각) × 90 / 나온 각입니다.
- **경고**
  - 벤드 사이 곧은 부분이 클램프 물림보다 짧을 때. 첫 벤드는 여유장 길이를 알립니다.
  - 마지막 다리가 최소 길이보다 짧을 때
  - 넣을 각도가 장비 최대 각보다 클 때(MS-BTB 180°)
  - 엔진 경고(곧은 부분 음수 등)
- **자를 길이** = 엔진 절단 길이 + 톱날 손실
