# 화면 문구 전수 검토표 (2026-10-03)

앱 화면 글 전체(약 1만 3천 개)를 8개 묶음으로 나눠 읽고, 고칠 것만 골랐습니다.

> **10-03 적용 완료**: 1절 16건은 내용 확인 뒤 고쳤고, 3절 표는 "확인 필요" 줄을 빼고 전부 적용했습니다. 사용자 결정: 과부하계전기, 배치도 모듈→부품·프로젝트→배치도, 뒤로 몰기→왼쪽으로 몰기, 계기 신호 진단→계기 신호 이상, 압력시험(붙여 씀). 저장 값으로도 쓰이는 이름(작업 유형·배치도 부품·빠른 실행·도면 표시 기록)은 예전 이름을 새 이름으로 읽게 했습니다. 남은 결정: 튜브 AUTO 게인 1/2" 20.0 mm(반경식 16.3 mm).

- 기준: 습니다/십시오체, 단추는 명사형, 묻는 창은 "~하시겠습니까?", 설명 줄 줄표(" — ") 금지, 현장 영어 용어(Normal Open, HART, trip 등)는 영어 그대로, 잔재·로스·실사 같은 현장 말은 그대로.
- 구분: **AI투·번역투** / **지은 말**(셈·잰·몫·넓이·연신율처럼 현장에서 안 쓰는 말) / **뜻 불명** / **용어 부정확** / **말투** / **불통일**(같은 것을 다른 이름으로) / **확인 필요**(글이 아니라 내용·숫자가 틀려 보임).
- 줄 번호는 오늘(10-03) 코드 기준입니다. "외 N곳"은 같은 글이 여러 곳에 있다는 뜻입니다.
- 들어가는 길이 없는 옛 화면(menu_screen, settings_screen, project/, vehicle/, history/, 태블릿용 inventory_tabs 등)은 대부분 뺐습니다.
