# 근태 관리: 점검 결과와 계산 근거 (2026-09-26)

홈 → 근태 관리(`lib/src/presentation/attendance/`). 기록 모양은 `lib/src/presentation/my_work_logs/models/attendance.dart`.
화면 글은 docs/계산기_용어_기준.md의 말투(습니다/십시오, 줄표 없음, 현장 말)를 따른다.
**이 화면은 개인 기록용 참고 계산이다. 급여·연차의 최종 기준은 회사 취업규칙·근로계약과 노동청 해석이다.**

## 1. 지금 구조 (점검 전)
- 서버 모음 `attendance_records`, 문서 이름 `{uid}__{yyyy-MM-dd}`, 칸: `date, type, checkIn, checkOut, uid`.
  서버 규칙은 문서 이름 앞부분 uid가 본인일 때만 읽고 쓴다(firestore.rules 116행, 이번에 손대지 않음).
- 종류 6개: 정상근무·연차·월차·반차·조퇴·특근. 연차·월차는 출퇴근 칸을 감춘다.
- `AttendanceCache.byDate`(날짜 → 종류)를 공수 계산이 쓴다: `manDaysOf`(연차·월차 0, 반차 ×0.5, 나머지 인원 그대로).
  쓰는 곳: report_pdf.dart(총 투입 인·일), report_tools.dart·summary_image.dart·daily_report_calendar_page.dart(근태 표),
  weekly_plan.dart(주간 투입), project_phase.dart(`phaseWorkStats`).
- 화면: 한 달 날짜 목록(1일~말일) + 종류별 개수 칩. 날짜를 누르면 아래 창에서 종류·출근·퇴근을 고른다.
  계산은 "근무 시간: 퇴근 − 출근"(자정 넘김 처리) 하나뿐이다.

## 6. 이번에 넣은 계산 (근거)
### 휴게시간 (제54조)
- 기본 휴게: 설정에서 고른다. **법정 최소(기본값)** / 없음 / 1시간 고정. 날마다 따로 고를 수도 있다(기록의 `breakMin`).
- 법정 최소는 근로시간(휴게 뺀 시간)이 4시간이면 30분, 8시간이면 1시간을 만족하는 가장 작은 값이다. 출근~퇴근 사이를
  S라 하면: S < 4시간 → 0분, 4시간 ≤ S < 8시간 30분 → 30분, S ≥ 8시간 30분 → 1시간.
  (8시간 30분에서 30분만 빼면 근로 8시간이라 1시간이 필요하다. 4시간에서 0분이면 근로 4시간이라 30분이 필요하다.)
- 실제 점심 1시간인 현장은 "1시간 고정"을 고르면 된다.

### 연장·야간·휴일 (제50·53·56조)
- 휴일 = 일요일(주휴일) + 관공서 공휴일 표(korean_holidays.dart). 토요일은 보통 무급 휴무일이라 연장으로 친다.
  회사가 토요일을 휴일로 정했으면 설정 "토요일 근무를 휴일근로로 계산"을 켠다.
- 자정을 넘긴 근무는 출근한 날의 근무로 묶되, **휴일 0시 이후 부분은 휴일근로**로 나눈다(행정해석).
- 휴게는 낮 시간·평일 부분에서 먼저 뺀다고 본다: 야간 = min(22~06시와 겹친 시간, 근로시간), 휴일 = min(휴일과 겹친 시간, 근로시간).
- 연장 = 하루 8시간 초과분(휴일 부분 제외) + 1주(월~일) 40시간 초과분. 주 계산은 날마다 min(평일 근로, 8시간)을 더해
  40시간을 넘는 날에 넘은 만큼 붙인다(두 번 세지 않음). 휴일근로는 연장 가산을 겹쳐 주지 않는다(제56조 제2항).
- 휴일 8시간 초과 = 휴일 하루(근무 한 번)에서 8시간 넘은 부분.
- 가산 시간 = 연장 × 0.5 + 야간 × 0.5 + 휴일 × 0.5 + 휴일 8시간 초과 × 0.5(초과분은 합쳐 100%). 통상시급을 곱하면 가산 수당이다.
- 주 52시간 경고: 한 주 근로 합계(휴일 포함) − 40시간과 하루 8시간 초과분 합(휴일 포함) 중 큰 값이 12시간을 넘으면 알린다.
  달의 첫 주·마지막 주도 앞뒤 달 기록을 같이 읽어 계산한다.

### 연차 잔여 (제60조, 입사일 기준)
- 입사일은 설정에서 넣는다(폰에만 저장).
- 입사 1년 미만: 입사일부터 한 달씩 끊어 **결근이 없는 달**마다 1일, 최대 11일. 입사 1년이 되면 남은 것은 없어진다(제7항 단서).
- 1년 이상: 지난 1년 출근율 80% 이상이면 15 + ⌊(근속연수 − 1) / 2⌋일, 최대 25일(근속 3년 16일, 5년 17일, 21년 25일).
  출근율 = (소정근로일 − 결근일) / 소정근로일, 소정근로일 = 평일(월~금) 중 공휴일이 아닌 날. 연차·반차·조퇴 날은 출근으로 본다.
  80% 미만이면 지난 1년 중 개근한 달마다 1일(제60조 제2항).
- 사용 = 연차·월차 1일, 반차 0.5일, 반반차 0.25일. 이번 연차 기간(입사 기념일 ~ 다음 기념일 전날)에 적은 것을 모두 더하고,
  오늘 뒤의 것은 "예정"으로 따로 보인다.
- 회사 부여 일수가 다르면(회계연도 기준·회사 추가 휴가·이월) 설정에서 이번 기간 부여 일수를 직접 넣는다.
- 결근 기록이 없으면 개근으로 본다: 앱을 쓰기 전 기간의 결근은 모른다.
